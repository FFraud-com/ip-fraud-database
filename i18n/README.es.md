# Base de fraude por IP, reconstruida cada 30 minutos

<p align="center"><b>1.262.193 direcciones IP maliciosas confirmadas y 553 redes con alto nivel de abuso. Cada dirección puntuada, categorizada y confirmada al menos dos veces de forma independiente.</b></p>

<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/es.svg?v=1789122608" alt="Ver la base en vivo en ffraud.com" width="540"></a></p>

Esta es la base abierta de fraude por IP que hay detrás de [ffraud.com](https://ffraud.com). Cada dirección fue observada atacando algo, confirmada al menos dos veces de forma independiente, puntuada de 0 a 100 y etiquetada con aquello en lo que se la pilló y con el tipo de infraestructura sobre la que corre. Los atacantes cambian de infraestructura sin parar, así que una lista de bloqueo vale lo que valga su última actualización: esta se reconstruye **cada 30 minutos** directamente desde el motor en producción. Lo que descargas es lo que está atacando internet ahora mismo. Sin registro, sin clave, sin límites. Métela tal cual en un cortafuegos, un WAF, un formulario de registro o una tubería antifraude.

## En pocas cifras

- **1.262.193** direcciones IP maliciosas confirmadas, cada una observada abusando **dos o más veces de forma independiente**
- **553** redes en las que las direcciones que observamos eran mayoritariamente maliciosas y con mucha presencia de proxies
- **219.575** dominios de correo desechable vienen también en este repositorio, así que un solo clon cubre las dos mitades de una comprobación de registro
- Cada dirección lleva una **puntuación de 0 a 100**, una **categoría de amenaza** y el **tipo de infraestructura** cuando se puede ver
- Se reconstruye y se publica **cada 30 minutos**. El historial de commits es el registro de cambios, y [`metadata.json`](metadata.json) lleva la hora exacta de construcción
- **Licencia MIT**, uso comercial incluido, sin atribución obligatoria
- CSV y TXT sin adornos. Nada que descomprimir, ningún esquema que aprender, ninguna biblioteca que instalar

## Qué te dice cada fila

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| Campo | Qué indica |
|------|------|
| `ip` | La dirección. Aparecen tanto IPv4 como IPv6 |
| `ffraud_score` | Nuestra propia puntuación de fraude de 0 a 100. Todo lo que se publica aquí está en 50 o por encima |
| `confirmations` | Cuántas veces observamos el abuso de forma independiente. Nada se lista por debajo de 2; las peores direcciones llegan a 30 o 40 |
| `category` | En qué se la pilló: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` o `abuse` |
| `type` | La infraestructura que hay detrás cuando es visible: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. Vacío cuando no podemos distinguirlo |

## Inicio rápido

```bash
# IP maliciosas confirmadas, con categoría y tipo
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# Las peores redes
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# Dominios de correo desechable
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

Cada archivo es texto plano con una línea de cabecera y unos pocos comentarios `#` al principio. Mándalo directamente a `ipset`, `iptables`, una regla de WAF o un `Set` en el lenguaje que ya estés usando.

## Consultar una sola dirección sin descargar nada

No hace falta llevarse la base entera para comprobar una sola cosa. La API pública no pide clave, no tiene tope diario y responde una a una a las mismas preguntas que este repositorio responde a granel:

```bash
# Información completa de una IP: puntuación, motivo, categorías
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# ¿Es esta dirección desechable?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# ¿Reparte este dominio buzones desechables?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Para agentes y asistentes: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) es el índice para máquinas, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) recoge toda la documentación en Markdown puro y [ffraud.com/openapi.json](https://ffraud.com/openapi.json) es la especificación OpenAPI. Los tres son públicos, no piden clave y están pensados para descargarse directamente. Quien prefiera una página tiene los verificadores gratuitos en [ffraud.com/tools](https://ffraud.com/tools).

## Cómo se construye la base

La construyen dos cosas: nuestra propia red de sensores honeypot, atacada sin descanso y que registra qué la ataca, y los reportes de quienes tienen los servidores recibiendo los golpes. No republicamos nada por la palabra de un tercero. Cada dirección la puntúa y la verifica el motor de ffraud antes de aparecer aquí.

El listón para entrar son **dos o más confirmaciones independientes**, porque un avistamiento suelto es ruido. Esa sola regla es la razón de que esta lista sea más corta que un volcado sin filtrar y valga más: contiene las direcciones que atacaban de verdad, no todo lo que alguien marcó una vez.

La puntuación, la categoría y el tipo de infraestructura son conclusiones nuestras, publicadas enteras para que puedas discutirlas. El método exacto de puntuación está explicado en [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology).

## Ayuda a construirla

Esta base crece con quienes la usan. Si administras servidores, fail2ban, un WAF o tus propios honeypots, mándanos lo que te ataca y lo publicamos: repórtalo en [ffraud.com/report](https://ffraud.com/report), apunta fail2ban al [punto de entrada listo para usar](https://ffraud.com/docs/contribute) o abre una issue aquí. Verificamos, quitamos duplicados y puntuamos cada envío; lo confirmado sale en la siguiente reconstrucción, es decir en menos de media hora, y con tu nombre si lo quieres.

## Una nota sobre la lista de redes

`high-abuse-networks.csv` indica qué proporción de las direcciones de cada red **hemos observado** comportándose de forma maliciosa. Es una medición del tráfico que llegó a nuestros sensores, no un juicio legal sobre ningún operador, y hay alojamientos legítimos que aparecen cuando sus clientes se portan mal. Si llevas una red listada y crees que la medición está mal, [dínoslo](https://ffraud.com/report) y lo revisamos en la siguiente reconstrucción.
