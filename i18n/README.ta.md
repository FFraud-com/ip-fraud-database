# IP மோசடித் தரவுத்தளம், ஒவ்வொரு 30 நிமிடமும் மீளக் கட்டப்படுகிறது

<p align="center"><b>1,249,757 உறுதிப்படுத்தப்பட்ட தீங்கிழைக்கும் IP முகவரிகள் மற்றும் 553 அதிக தவறான பயன்பாடு கொண்ட வலையமைப்புகள். ஒவ்வொரு முகவரிக்கும் மதிப்பெண், வகை, மற்றும் குறைந்தது இரு முறை தனித்த உறுதிப்படுத்தல்.</b></p>
<p align="center"><sub>MIT உரிமம் &middot; பதிவு இல்லை, API சாவி இல்லை, கோரிக்கை வரம்பு இல்லை &middot; புதுப்பிக்கப்பட்டது 10.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/ta.svg?v=1789009201" alt="ffraud.com இல் நேரடித் தரவுத்தளத்தைப் பாருங்கள்" width="540"></a></p>

இது [ffraud.com](https://ffraud.com) பின்னால் நிற்கும் திறந்த IP மோசடித் தரவுத்தளம். இதிலுள்ள ஒவ்வொரு முகவரியும் எதையாவது தாக்கிக் கொண்டிருக்கும்போது கவனிக்கப்பட்டது, குறைந்தது இரு முறை தனித்து உறுதிப்படுத்தப்பட்டது, 0 முதல் 100 வரை மதிப்பெண் பெற்றது, மேலும் எதில் பிடிபட்டது என்பதும் எத்தகைய உள்கட்டமைப்பில் இயங்குகிறது என்பதும் குறிக்கப்பட்டது. தாக்குபவர்கள் இடைவிடாமல் உள்கட்டமைப்பை மாற்றுகிறார்கள், எனவே ஒரு தடுப்புப் பட்டியலின் மதிப்பு அதன் கடைசிப் புதுப்பிப்புக்குச் சமமே: இது **ஒவ்வொரு 30 நிமிடமும்** இயங்கும் இயந்திரத்திலிருந்து நேரடியாக மீளக் கட்டப்படுகிறது. நீங்கள் பதிவிறக்குவது இந்தக் கணமே இணையத்தைத் தாக்கிக் கொண்டிருப்பதுதான். பதிவு இல்லை, சாவி இல்லை, வரம்பு இல்லை. நேராக ஒரு ஃபயர்வால், WAF, பதிவு படிவம் அல்லது மோசடிச் சரிபார்ப்பு வழியில் ஊற்றுங்கள்.

## சுருக்கமாக

- **1,249,757** உறுதிப்படுத்தப்பட்ட தீங்கிழைக்கும் IP முகவரிகள், ஒவ்வொன்றும் **இரு முறை அல்லது அதற்கு மேல் தனித்து** தவறாகப் பயன்படுத்தப்படுவது கவனிக்கப்பட்டது
- **553** வலையமைப்புகள், அவற்றில் நாங்கள் கவனித்த முகவரிகள் பெரும்பாலும் தீங்கிழைப்பவையாகவும் ப்ராக்ஸி நிறைந்தவையாகவும் இருந்தன
- **219,530** ஒருமுறை பயன்பாட்டு மின்னஞ்சல் டொமைன்களும் இதே களஞ்சியத்தில் வருகின்றன, எனவே ஒரு முறை குளோன் செய்தால் பதிவுச் சரிபார்ப்பின் இரு பாதிகளும் மூடப்படுகின்றன
- ஒவ்வொரு முகவரியும் **0 முதல் 100 வரை மதிப்பெண்**, ஒரு **அச்சுறுத்தல் வகை**, மற்றும் தெரியும்போது **உள்கட்டமைப்பு வகை** ஆகியவற்றைச் சுமக்கிறது
- **ஒவ்வொரு 30 நிமிடமும்** மீளக் கட்டப்பட்டு வெளியிடப்படுகிறது. commit வரலாறே மாற்றப் பதிவு, மேலும் [`metadata.json`](metadata.json) கட்டமைப்பின் துல்லியமான நேரத்தைச் சுமக்கிறது
- **MIT உரிமம்**, வணிகப் பயன்பாடு உட்பட, பெயர் குறிப்பிடல் தேவையில்லை
- எளிய CSV மற்றும் TXT. பிரிக்க எந்தக் காப்பகமும் இல்லை, கற்க எந்தத் திட்டமும் இல்லை, நிறுவ எந்த நூலகமும் இல்லை

```bash
# இந்த முகவரி ஒருமுறை பயன்பாட்டுடையதா?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# இந்த டொமைன் தூக்கி எறியும் அஞ்சல் பெட்டிகளை வழங்குகிறதா?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

முகவர்களுக்கும் உதவியாளர்களுக்கும்: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) இயந்திரங்களுக்கான அட்டவணை, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) முழு ஆவணங்களையும் எளிய Markdown ஆக வைத்திருக்கிறது, [ffraud.com/openapi.json](https://ffraud.com/openapi.json) என்பது OpenAPI விவரக்குறிப்பு. மூன்றுமே பொதுவானவை, சாவி கேட்பதில்லை, நேரடியாக எடுத்துக்கொள்ளவே உருவாக்கப்பட்டவை. பக்கம் விரும்புபவர்களுக்கு இலவச சரிபார்ப்புக் கருவிகள் [ffraud.com/tools](https://ffraud.com/tools) இல் உள்ளன.

## இந்தத் தரவுத்தளம் எப்படிக் கட்டப்படுகிறது

இரண்டு விஷயங்கள் இதைக் கட்டுகின்றன: இடைவிடாமல் தாக்கப்படும், தன்னைத் தாக்குவது எது என்பதைப் பதிவு செய்யும் எங்கள் சொந்த ஹனிபாட் உணரி வலையமைப்பு, மற்றும் சேவையகங்கள் அடிவாங்கிக் கொண்டிருக்கும் மனிதர்களின் அறிக்கைகள். மற்றவர் சொன்னார் என்பதற்காக நாங்கள் எதையும் மறுவெளியீடு செய்வதில்லை. இங்கு தோன்றுவதற்கு முன் ஒவ்வொரு முகவரிக்கும் ffraud இயந்திரம் மதிப்பெண் இட்டுச் சரிபார்க்கிறது.

பட்டியலில் சேர்வதற்கான வரம்பு **குறைந்தது இரு தனித்த உறுதிப்படுத்தல்கள்**, ஏனெனில் ஒரே ஒரு பார்வை வெறும் இரைச்சல். இந்த ஒரே விதிதான் இந்தப் பட்டியலை வடிகட்டப்படாத குவியலைவிடச் சிறியதாகவும், அதைவிட மதிப்புமிக்கதாகவும் ஆக்குகிறது: இதில் உண்மையிலேயே தாக்கிய முகவரிகள் இருக்கின்றன, யாரோ ஒருமுறை குறியிட்ட எல்லாம் அல்ல.

மதிப்பெண், வகை, உள்கட்டமைப்பு வகை ஆகியவை எங்கள் சொந்த முடிவுகள், நீங்கள் மறுக்க முடியும் வகையில் முழுமையாக வெளியிடப்படுகின்றன. துல்லியமான மதிப்பெண் முறை [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) இல் விவரிக்கப்பட்டுள்ளது.

## கட்ட உதவுங்கள்

இந்தத் தரவுத்தளம் அதைப் பயன்படுத்துபவர்களுடன் சேர்ந்தே வளர்கிறது. நீங்கள் சேவையகங்கள், fail2ban, WAF அல்லது சொந்த ஹனிபாட்கள் இயக்கினால், உங்களைத் தாக்குவதை எங்களுக்கு அனுப்புங்கள், நாங்கள் வெளியிடுகிறோம்: [ffraud.com/report](https://ffraud.com/report) இல் தெரிவியுங்கள், fail2ban ஐ [தயார் நிலை முனைப்புள்ளிக்கு](https://ffraud.com/docs/contribute) திருப்புங்கள், அல்லது இங்கேயே ஒரு issue திறங்கள். ஒவ்வொரு சமர்ப்பிப்பையும் சரிபார்த்து, நகல்களை நீக்கி, மதிப்பெண் இடுகிறோம்; உறுதிப்படுத்தப்பட்டவை அடுத்த கட்டமைப்பில், அதாவது அரை மணி நேரத்திற்குள், வெளியாகும், விரும்பினால் உங்கள் பெயருடன்.

## வலையமைப்புப் பட்டியல் குறித்த ஒரு குறிப்பு

`high-abuse-networks.csv` ஒவ்வொரு வலையமைப்பின் முகவரிகளில் எத்தனை பங்கு **நாங்கள் கவனித்தவரை** தீங்கிழைக்கும் விதத்தில் நடந்துகொண்டன என்பதைத் தெரிவிக்கிறது. இது எங்கள் உணரிகளை வந்தடைந்த போக்குவரத்தின் அளவீடு, எந்த இயக்குநர் மீதான சட்ட முடிவும் அல்ல, மேலும் வாடிக்கையாளர்கள் தவறாக நடக்கும்போது நேர்மையான ஹோஸ்டிங் நிறுவனங்களும் அதில் வந்துவிடும். பட்டியலிடப்பட்ட வலையமைப்பை நீங்கள் இயக்கி, அளவீடு தவறு என்று கருதினால், [எங்களிடம் சொல்லுங்கள்](https://ffraud.com/report), அடுத்த கட்டமைப்பில் மீண்டும் சரிபார்ப்போம்.
