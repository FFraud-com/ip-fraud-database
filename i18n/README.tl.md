# Database ng pandarayang IP, muling binubuo kada 30 minuto

<p align="center"><b>1,260,836 nakumpirmang mapaminsalang IP address at 553 network na mataas ang pang-aabuso. Bawat address ay may iskor, kategorya, at hindi bababa sa dalawang malayang kumpirmasyon.</b></p>
<p align="center"><sub>Lisensyang MIT &middot; walang rehistro, walang API key, walang limitasyon sa kahilingan &middot; na-update 11.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/tl.svg?v=1789104612" alt="Tingnan ang buhay na database sa ffraud.com" width="540"></a></p>

Ito ang bukas na database ng pandarayang IP na nasa likod ng [ffraud.com](https://ffraud.com). Bawat address dito ay nakitang umaatake sa isang bagay, nakumpirma nang hindi bababa sa dalawang beses nang malaya, binigyan ng iskor mula 0 hanggang 100, at tinatakan ng kung ano ang ginagawa nito nang mahuli at kung anong uri ng imprastraktura ang tinatakbuhan nito. Palit nang palit ng imprastraktura ang mga umaatake, kaya kasinghalaga lang ng huling update nito ang isang blocklist: ang isang ito ay muling binubuo **kada 30 minuto** mismo mula sa umaandar na makina. Ang dina-download mo ay ang umaatake sa internet ngayon mismo. Walang rehistro, walang key, walang limitasyon. Ibuhos ito nang diretso sa firewall, WAF, form ng pagpaparehistro, o sa daloy ng pagsusuri sa pandaraya.

## Sa maikling salita

- **1,260,836** nakumpirmang mapaminsalang IP address, bawat isa ay nakitang nang-aabuso nang **dalawa o higit pang malayang beses**
- **553** network kung saan ang mga address na aming naobserbahan ay halos puro mapaminsala at punô ng proxy
- **219,575** disposable na email domain ang kasama rin sa repositoryong ito, kaya isang clone lang ay sakop na ang dalawang panig ng pagsusuri sa pagpaparehistro
- Bawat address ay may **iskor mula 0 hanggang 100**, isang **kategorya ng banta**, at ang **uri ng imprastraktura** kapag nakikita
- Muling binubuo at inilalathala **kada 30 minuto**. Ang kasaysayan ng commit ang talaan ng pagbabago, at nasa [`metadata.json`](metadata.json) ang eksaktong oras ng build
- **Lisensyang MIT**, kasama ang komersyal na paggamit, walang kailangang pagkilala
- Payak na CSV at TXT. Walang archive na bubuksan, walang schema na aaralin, walang library na ii-install

## Ano ang sinasabi ng bawat hilera

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| Field | Ano ang sinasabi |
|------|------|
| `ip` | Ang address. Lumalabas kapwa ang IPv4 at IPv6 |
| `ffraud_score` | Ang sarili naming iskor ng pandaraya mula 0 hanggang 100. Lahat ng inilalathala rito ay 50 pataas |
| `confirmations` | Ilang malayang beses naming naobserbahan ang pang-aabuso. Walang naililista sa ibaba ng 2; ang pinakamasasamang address ay umaabot sa 30 hanggang 40 |
| `category` | Kung ano ang ginagawa nang mahuli: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` o `abuse` |
| `type` | Ang imprastrakturang nasa likod kapag nakikita: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. Blangko kapag hindi namin matukoy |

## Mabilisang simula

```bash
# Nakumpirmang mapaminsalang IP, may kategorya at uri
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# Ang pinakamasasamang network
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# Disposable na email domain
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

Bawat file ay payak na teksto na may isang linyang panimula at ilang `#` na komento sa umpisa. Idiretso ito sa `ipset`, `iptables`, sa isang panuntunan ng WAF, o sa isang `Set` sa wikang ginagamit mo na.

## Suriin ang isang address nang walang dina-download

Hindi mo kailangang kunin ang buong database para suriin ang isang bagay. Ang pampublikong API ay hindi humihingi ng key, walang pang-araw-araw na takda, at isa-isang sinasagot ang mismong mga tanong na sinasagot ng repositoryong ito nang maramihan:

```bash
# Buong impormasyon tungkol sa isang IP: iskor, dahilan, kategorya
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Disposable ba ang address na ito?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Namimigay ba ang domain na ito ng disposable na mailbox?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Para sa mga ahente at katulong: ang [ffraud.com/llms.txt](https://ffraud.com/llms.txt) ang index para sa makina, ang [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) ang buong dokumentasyon bilang purong Markdown, at ang [ffraud.com/openapi.json](https://ffraud.com/openapi.json) ang OpenAPI spec. Pampubliko ang tatlo, hindi humihingi ng key, at ginawa talaga para kunin nang direkta. Ang mas gusto ng pahina, nasa [ffraud.com/tools](https://ffraud.com/tools) ang mga libreng pansuri.

## Paano binubuo ang database

Dalawang bagay ang bumubuo nito: ang sarili naming network ng honeypot sensor, na inaatake nang walang tigil at nagtatala kung ano ang umaatake rito, at ang mga ulat mula sa mga taong binubugbog ang mga server. Walang inilalathala uli batay lamang sa sabi ng iba. Bawat address ay binibigyan ng iskor at bineberipika ng makina ng ffraud bago lumitaw dito.

Ang pamantayan sa pagpasok ay **dalawa o higit pang malayang kumpirmasyon**, dahil ingay lamang ang isang beses na pagkakakita. Ang iisang patakarang iyon ang nagpapaikli sa listahang ito kaysa sa hindi sinalang bunton at nagpapahalaga rito nang higit: naririto ang mga address na talagang umaatake, hindi lahat ng minsang tinandaan ng kung sino.

Ang iskor, kategorya at uri ng imprastraktura ay sarili naming konklusyon, inilalathala nang buo para may mapagtalunan ka. Nasa [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) ang eksaktong paraan ng pagbibigay-iskor.

## Mga tanong

<details>
<summary><b>Gaano talaga kadalas ito nag-a-update?</b></summary>

Kada 30 minuto: muling binubuo mula sa umaandar na makina at inilalathala rito. Hindi ito panggabing dump. Ang listahan ng commit ng repositoryong ito ang tapat na talaan, at nasa [`metadata.json`](metadata.json) ang eksaktong oras ng build ng kopya mo sa UTC.

</details>

<details>
<summary><b>Puwede ko bang gamitin ito sa produktong pangkomersyo?</b></summary>

Oo. MIT: walang kailangang pagkilala, walang hiwalay na lisensyang pangkomersyo, walang bilangan ng upuan, at walang tatanungin. Kung makakatipid ka rito, matutuwa kaming marinig, pero wala kang utang sa amin.

</details>

<details>
<summary><b>Bakit nasa listahan ang address ko?</b></summary>

Dahil nakita itong umaatake sa isang bagay nang hindi bababa sa dalawang beses. Hanapin ito sa [ffraud.com](https://ffraud.com) para makita ang iskor, mga kategorya at ang dahilan sa simpleng salita. Kung mali ito, o nalinis na ang makina, sabihin sa amin sa [ffraud.com/report](https://ffraud.com/report) at susuriing muli sa susunod na build.

</details>

<details>
<summary><b>Ano ang pinagkaiba nito sa malalaking bayad na tagapagbigay?</b></summary>

Libre ito, MIT ang lisensya, walang key at walang takda, at mababasa mo mismo kung bakit nakalista ang bawat address. Puwede mo ring i-download ang buong database, na hindi pinapayagan ng karamihan sa bayad na produkto sa anumang halaga.

</details>

<details>
<summary><b>May API ba para sa isahang paghahanap?</b></summary>

Mayroon, at hindi ito nangangailangan ng key. Tingnan ang bahaging nasa itaas o ang dokumentasyon sa [ffraud.com/docs](https://ffraud.com/docs).

</details>

## Tumulong sa pagbuo

Lumalaki ang database na ito kasabay ng mga gumagamit nito. Kung nagpapatakbo ka ng mga server, fail2ban, WAF o sariling honeypot, ipadala sa amin ang umaatake sa iyo at ilalathala namin: mag-ulat sa [ffraud.com/report](https://ffraud.com/report), ituro ang fail2ban sa [handa nang endpoint](https://ffraud.com/docs/contribute), o magbukas ng issue dito. Bineberipika, tinatanggal ang doble at binibigyan ng iskor ang bawat isinumite; ang nakumpirma ay sumasama sa susunod na build, ibig sabihin sa loob ng kalahating oras, na may pangalan mo kung gusto mo.

## Isang paalala tungkol sa listahan ng network

Iniuulat ng `high-abuse-networks.csv` kung gaano kalaking bahagi ng mga address ng bawat network ang **aming naobserbahan** na kumikilos nang mapaminsala. Sukat ito ng trapikong nakarating sa aming mga sensor, hindi hatol na legal sa sinumang nagpapatakbo, at napapasama rito ang mga tapat na kompanya ng hosting kapag masama ang asal ng kanilang mga kliyente. Kung nagpapatakbo ka ng nakalistang network at sa palagay mo mali ang sukat, [sabihin sa amin](https://ffraud.com/report) at susuriin naming muli sa susunod na build.
