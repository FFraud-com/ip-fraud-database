# Base de fraude por IP, reconstruída a cada 30 minutos

<p align="center"><b>1.253.634 endereços IP maliciosos confirmados e 553 redes com alto nível de abuso. Cada endereço pontuado, categorizado e confirmado pelo menos duas vezes de forma independente.</b></p>
<p align="center"><sub>Licença MIT &middot; sem cadastro, sem chave de API, sem limite de requisições &middot; atualizado em 10.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/pt-BR.svg?v=1789041610" alt="Ver a base ao vivo em ffraud.com" width="540"></a></p>

Esta é a base aberta de fraude por IP que está por trás do [ffraud.com](https://ffraud.com). Cada endereço aqui foi observado atacando alguma coisa, confirmado pelo menos duas vezes de forma independente, pontuado de 0 a 100 e rotulado com aquilo em que foi pego e com o tipo de infraestrutura em que roda. Atacantes trocam de infraestrutura o tempo todo, então uma lista de bloqueio vale o quanto valer sua última atualização: esta é reconstruída **a cada 30 minutos** direto do motor em produção. O que você baixa é o que está atacando a internet agora. Sem cadastro, sem chave, sem limites. Jogue direto num firewall, num WAF, num formulário de cadastro ou numa esteira antifraude.

## Em números

- **1.253.634** endereços IP maliciosos confirmados, cada um observado abusando **duas ou mais vezes de forma independente**
- **553** redes em que os endereços que observamos eram majoritariamente maliciosos e com forte presença de proxies
- **219.530** domínios de e-mail descartável também vêm neste repositório, então um único clone cobre as duas metades de uma checagem de cadastro
- Todo endereço carrega uma **pontuação de 0 a 100**, uma **categoria de ameaça** e o **tipo de infraestrutura** quando dá para ver
- Reconstruída e publicada **a cada 30 minutos**. O histórico de commits é o registro de mudanças, e [`metadata.json`](metadata.json) traz a hora exata da build
- **Licença MIT**, uso comercial incluído, sem atribuição obrigatória
- CSV e TXT puros. Nada para descompactar, nenhum esquema para aprender, nenhuma biblioteca para instalar

## O que cada linha diz

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| Campo | O que indica |
|------|------|
| `ip` | O endereço. Aparecem tanto IPv4 quanto IPv6 |
| `ffraud_score` | Nossa própria pontuação de fraude de 0 a 100. Tudo publicado aqui está em 50 ou acima |
| `confirmations` | Quantas vezes observamos o abuso de forma independente. Nada é listado abaixo de 2; os piores endereços chegam a 30 ou 40 |
| `category` | Em que foi pego: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` ou `abuse` |
| `type` | A infraestrutura por trás quando visível: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. Vazio quando não conseguimos distinguir |

```bash
# IPs maliciosos confirmados, com categoria e tipo
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# As piores redes
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# Domínios de e-mail descartável
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

Todo arquivo é texto puro com uma linha de cabeçalho e alguns comentários `#` no início. Mande direto para `ipset`, `iptables`, uma regra de WAF ou um `Set` na linguagem que você já usa.

## Consultar um endereço sem baixar nada

Não precisa levar a base inteira para checar uma coisa só. A API pública não pede chave, não tem teto diário e responde uma a uma às mesmas perguntas que este repositório responde em lote:

```bash
# Informação completa de um IP: pontuação, motivo, categorias
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Este endereço é descartável?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Este domínio distribui caixas de e-mail descartáveis?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Para agentes e assistentes: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) é o índice para máquinas, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) traz toda a documentação em Markdown puro e [ffraud.com/openapi.json](https://ffraud.com/openapi.json) é a especificação OpenAPI. Os três são públicos, não pedem chave e foram feitos para serem buscados diretamente. Quem prefere uma página tem os verificadores gratuitos em [ffraud.com/tools](https://ffraud.com/tools).

## Como a base é construída

Duas coisas a constroem: nossa própria rede de sensores honeypot, atacada sem parar e que registra o que a ataca, e os relatos de quem está com os servidores apanhando. Nada é republicado só porque um terceiro disse. Todo endereço é pontuado e verificado pelo motor do ffraud antes de aparecer aqui.

O critério para entrar são **duas ou mais confirmações independentes**, porque um avistamento sozinho é ruído. Essa única regra é o motivo de esta lista ser menor que um despejo sem filtro e valer mais: ela contém os endereços que realmente atacaram, não tudo que alguém marcou uma vez.

A pontuação, a categoria e o tipo de infraestrutura são conclusões nossas, publicadas por inteiro para você poder discordar. O método exato de pontuação está descrito em [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology).

## Ajude a construir

Esta base cresce com quem a usa. Se você administra servidores, fail2ban, um WAF ou seus próprios honeypots, mande o que está te atacando e nós publicamos: reporte em [ffraud.com/report](https://ffraud.com/report), aponte o fail2ban para o [endpoint pronto](https://ffraud.com/docs/contribute) ou abra uma issue aqui. Verificamos, removemos duplicatas e pontuamos cada envio; o que é confirmado entra na próxima reconstrução, ou seja, em menos de meia hora, com crédito se você quiser.

## Uma observação sobre a lista de redes

O `high-abuse-networks.csv` informa a proporção dos endereços de cada rede que **nós observamos** se comportando de forma maliciosa. É uma medição do tráfego que chegou aos nossos sensores, não um julgamento jurídico sobre qualquer operadora, e hospedagens sérias aparecem quando seus clientes se comportam mal. Se você opera uma rede listada e acha que a medição está errada, [avise](https://ffraud.com/report) e revisamos na próxima reconstrução.
