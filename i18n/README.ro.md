# Baza de fraudă IP, reconstruită la fiecare 30 de minute

<p align="center"><b>1.240.139 adrese IP rău intenționate confirmate și 553 rețele cu abuz ridicat. Fiecare adresă are scor, categorie și cel puțin două confirmări independente.</b></p>
<p align="center"><sub>Licență MIT &middot; fără înregistrare, fără cheie API, fără limite de cereri &middot; actualizat 08.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/ro.svg?v=1788910209" alt="Vezi baza live pe ffraud.com" width="540"></a></p>

Aceasta este baza deschisă de fraudă IP din spatele [ffraud.com](https://ffraud.com). Fiecare adresă din ea a fost observată atacând ceva, confirmată independent de cel puțin două ori, punctată de la 0 la 100 și etichetată cu ce făcea când a fost prinsă și pe ce fel de infrastructură rulează. Atacatorii își schimbă infrastructura neîncetat, așa că o listă de blocare valorează exact cât ultima ei actualizare: aceasta se reconstruiește **la fiecare 30 de minute** direct din motorul aflat în funcțiune. Ce descarci este ceea ce atacă internetul chiar acum. Fără înregistrare, fără cheie, fără limite. Bag-o direct într-un firewall, un WAF, un formular de înregistrare sau un flux antifraudă.

## Pe scurt

- **1.240.139** adrese IP rău intenționate confirmate, fiecare observată abuzând **de două sau mai multe ori, independent**
- **553** rețele în care adresele pe care le-am observat erau în mare parte rău intenționate și pline de proxy
- **219.506** domenii de e-mail de unică folosință vin și ele în acest depozit, așa că o singură clonare acoperă ambele jumătăți ale unei verificări la înregistrare
- Fiecare adresă poartă un **scor de la 0 la 100**, o **categorie de amenințare** și **tipul de infrastructură** când se vede
- Se reconstruiește și se publică **la fiecare 30 de minute**. Istoricul commit-urilor este jurnalul de modificări, iar [`metadata.json`](metadata.json) poartă ora exactă a construcției
- **Licență MIT**, utilizare comercială inclusă, fără atribuire obligatorie
- CSV și TXT simple. Nimic de dezarhivat, nicio schemă de învățat, nicio bibliotecă de instalat

## Ce spune fiecare rând

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| Câmp | Ce arată |
|------|------|
| `ip` | Adresa. Apar și IPv4, și IPv6 |
| `ffraud_score` | Scorul nostru de fraudă, de la 0 la 100. Tot ce se publică aici este 50 sau peste |
| `confirmations` | De câte ori am observat abuzul independent. Sub 2 nu se listează nimic; cele mai grave adrese ajung la 30 sau 40 |
| `category` | Ce făcea când a fost prinsă: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` sau `abuse` |
| `type` | Infrastructura din spate când se vede: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. Gol când nu putem distinge |

## Start rapid

```bash
# IP-uri rău intenționate confirmate, cu categorie și tip
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# Cele mai rele rețele
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# Domenii de e-mail de unică folosință
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

Fiecare fișier este text simplu, cu un rând de antet și câteva comentarii `#` la început. Trimite-l direct în `ipset`, `iptables`, o regulă WAF sau un `Set` în limbajul pe care oricum îl folosești.

## Verifică o singură adresă fără să descarci nimic

Nu trebuie să iei toată baza ca să verifici un singur lucru. API-ul public nu cere cheie, nu are plafon zilnic și răspunde bucată cu bucată la aceleași întrebări la care depozitul răspunde în masă:

```bash
# Informații complete despre un IP: scor, motiv, categorii
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Este această adresă de unică folosință?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Împarte acest domeniu căsuțe de unică folosință?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Pentru agenți și asistenți: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) este indexul pentru mașini, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) cuprinde toată documentația în Markdown simplu, iar [ffraud.com/openapi.json](https://ffraud.com/openapi.json) este specificația OpenAPI. Toate trei sunt publice, nu cer cheie și sunt făcute ca să fie descărcate direct. Cine preferă o pagină găsește verificatoarele gratuite la [ffraud.com/tools](https://ffraud.com/tools).

## Cum se construiește baza

O construiesc două lucruri: propria noastră rețea de senzori honeypot, atacată fără încetare și care înregistrează ce o atacă, și raportările celor cărora le încasează serverele. Nu republicăm nimic doar pe cuvântul altcuiva. Fiecare adresă este punctată și verificată de motorul ffraud înainte să apară aici.

Pragul pentru a intra în listă sunt **două sau mai multe confirmări independente**, fiindcă o singură observare este zgomot. Tocmai această unică regulă face lista mai scurtă decât o grămadă nefiltrată și mai valoroasă decât ea: conține adresele care chiar atacau, nu tot ce a marcat cineva vreodată o dată.

Scorul, categoria și tipul de infrastructură sunt concluziile noastre, publicate în întregime ca să le poți contesta. Metoda exactă de punctare este descrisă la [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology).

## O notă despre lista de rețele

`high-abuse-networks.csv` arată ce parte din adresele fiecărei rețele **am observat noi** comportându-se rău intenționat. Este o măsurătoare a traficului care a ajuns la senzorii noștri, nu o judecată juridică asupra vreunui operator, iar găzduiri serioase apar acolo când clienții lor se poartă urât. Dacă administrezi o rețea listată și consideri măsurătoarea greșită, [spune-ne](https://ffraud.com/report) și o reverificăm la următoarea construcție.
