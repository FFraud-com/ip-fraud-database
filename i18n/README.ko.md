# IP 사기 데이터베이스, 30분마다 재생성

<p align="center"><b>확인된 악성 IP 주소 1,271,601개와 악용이 심한 네트워크 537개. 모든 주소에 점수와 분류가 있고, 최소 두 번 독립적으로 확인되었습니다.</b></p>
<p align="center"><sub>MIT 라이선스 &middot; 가입 불필요, API 키 불필요, 요청 제한 없음 &middot; 업데이트 13.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/ko.svg?v=1789281002" alt="ffraud.com에서 실시간 데이터베이스 보기" width="540"></a></p>

[ffraud.com](https://ffraud.com)을 떠받치는 공개 IP 사기 데이터베이스입니다. 여기 있는 주소는 모두 무언가를 공격하는 중에 관측되었고, 최소 두 번 독립적으로 확인되었으며, 0에서 100까지 점수가 매겨지고, 무엇을 하다 잡혔는지와 어떤 인프라에서 도는지까지 표시되어 있습니다. 공격자는 인프라를 끊임없이 바꾸기 때문에 차단 목록의 가치는 마지막 갱신 시점이 정합니다. 이 목록은 **30분마다** 살아 있는 엔진에서 바로 다시 만들어집니다. 내려받는 것이 지금 이 순간 인터넷을 공격하고 있는 것입니다. 가입도, API 키도, 요청 제한도 없습니다. 방화벽이나 WAF, 가입 폼, 사기 탐지 파이프라인에 그대로 넣으면 됩니다.

## 핵심 수치

- 확인된 악성 IP 주소 **1,271,601개**. 각각 **두 번 이상 독립적으로** 악용이 관측되었습니다
- **537개** 네트워크. 저희가 관측한 주소 대부분이 악성이었고 프록시 비중이 높았던 곳입니다
- 일회용 이메일 도메인 **219,617개**도 이 저장소에 함께 들어 있어, 한 번 클론하면 가입 검사의 양쪽을 모두 덮습니다
- 모든 주소에 **0에서 100까지의 점수**, **위협 분류**, 그리고 파악되는 경우 **인프라 유형**이 붙습니다
- **30분마다** 다시 만들어 푸시합니다. 커밋 기록이 곧 변경 기록이고, [`metadata.json`](metadata.json)에 정확한 빌드 시각이 있습니다
- **MIT 라이선스**, 상업적 이용 포함, 출처 표기 불필요
- 그냥 CSV와 TXT입니다. 풀어야 할 압축도, 익혀야 할 스키마도, 설치할 클라이언트 라이브러리도 없습니다

## 저장소 구성

| 파일 | 행 수 | 설명 |
|------|------:|------|
| [`threat-ips/confirmed-abusive.csv`](../threat-ips/confirmed-abusive.csv) | 1,271,601 | 악성 주소. 각각 두 번 이상 확인되었고, 0에서 100까지의 점수, 위협 분류(c2, 멀웨어, 봇넷, 무차별 대입, 웹 공격, 스캐너, 피싱, 스팸), 그리고 알려진 경우 인프라 유형(proxy, vpn, tor, datacenter, mobile)이 함께 들어 있습니다 |
| [`asn-reputation/high-abuse-networks.csv`](../asn-reputation/high-abuse-networks.csv) | 537 | 관측된 주소 대부분이 악성이고 프록시 비중이 높았던 네트워크. 방탄 호스팅의 특징입니다 |
| [`disposable-email-domains.txt`](../disposable-email-domains.txt) | 219,617 | 일회용·임시 이메일 도메인, 한 줄에 하나 |
| [`ip-intelligence/examples.json`](../ip-intelligence/examples.json) | 샘플 | 주소별 전체 정보: 점수, 쉬운 말로 쓴 근거, 그리고 붙은 모든 분류 |
| [`metadata.json`](../metadata.json) | &mdash; | 실시간 건수와 UTC 빌드 시각. 스크립트가 자기 사본이 얼마나 최신인지 알 수 있습니다 |

## 각 행이 알려주는 것

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| 필드 | 의미 |
|------|------|
| `ip` | 주소. IPv4와 IPv6 둘 다 나옵니다 |
| `ffraud_score` | 저희 자체 0~100 사기 점수. 여기 공개된 것은 모두 50 이상입니다 |
| `confirmations` | 그 악용을 독립적으로 관측한 횟수. 2회 미만은 싣지 않으며, 최악의 주소는 30에서 40에 이릅니다 |
| `category` | 무엇을 하다 잡혔는지: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam`, `abuse` |
| `type` | 파악되는 경우 뒤에 있는 인프라: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. 알 수 없으면 비어 있습니다 |

## 빠른 시작

```bash
# 확인된 악성 IP, 분류와 유형 포함
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# 가장 나쁜 네트워크
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# 일회용 이메일 도메인
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

모든 파일은 헤더 한 줄과 앞부분의 `#` 주석 몇 줄이 붙은 평범한 텍스트입니다. `ipset`, `iptables`, WAF 규칙, 또는 이미 쓰고 있는 언어의 `Set`으로 바로 흘려보내면 됩니다.

## 내려받지 않고 하나만 조회하기

하나 확인하려고 데이터베이스 전체를 받을 필요는 없습니다. 공개 API는 키가 필요 없고 일일 상한도 없으며, 이 저장소가 대량으로 답하는 것과 같은 질문에 하나씩 답합니다.

```bash
# IP 하나의 전체 정보: 점수, 근거, 분류
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# 이 주소는 일회용인가?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# 이 도메인이 임시 메일함을 나눠주는가?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

에이전트와 어시스턴트를 위한 안내: [ffraud.com/llms.txt](https://ffraud.com/llms.txt)가 기계용 색인, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt)가 모든 문서의 순수 마크다운 버전, [ffraud.com/openapi.json](https://ffraud.com/openapi.json)이 OpenAPI 명세입니다. 셋 다 공개되어 있고 키가 필요 없으며, 직접 가져가라고 만든 것입니다. 페이지가 편한 분은 [ffraud.com/tools](https://ffraud.com/tools)의 무료 검사 도구를 쓰시면 됩니다.

## 이 데이터베이스가 만들어지는 방식

두 가지가 이걸 만듭니다. 끊임없이 공격받으면서 무엇이 공격했는지 기록하는 자체 허니팟 센서망, 그리고 실제로 서버를 두들겨 맞는 사람들의 신고입니다. 남의 말만 듣고 다시 퍼뜨리는 것은 하나도 없습니다. 모든 주소는 여기 실리기 전에 ffraud 엔진이 점수를 매기고 검증합니다.

등재 기준은 **두 번 이상의 독립적인 확인**입니다. 한 번의 목격은 잡음이니까요. 바로 이 규칙 하나 때문에 이 목록은 걸러지지 않은 더미보다 작고, 더 값집니다. 실제로 공격한 주소만 들어 있고, 누군가 한 번 표시했을 뿐인 것은 들어 있지 않습니다.

점수도, 분류도, 인프라 유형도 저희의 판단이며, 반박할 수 있도록 전부 공개합니다. 점수를 매기는 구체적인 방법은 [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology)에 적어 두었습니다.

## 자주 묻는 질문

<details>
<summary><b>실제로 얼마나 자주 갱신되나요?</b></summary>

30분마다입니다. 살아 있는 엔진에서 다시 만들어 여기로 푸시합니다. 밤에 한 번 떠내는 덤프가 아닙니다. 이 저장소의 커밋 목록이 정직한 기록이고, [`metadata.json`](metadata.json)에 지금 가진 사본의 정확한 UTC 빌드 시각이 있습니다.

</details>

<details>
<summary><b>상용 제품에 써도 되나요?</b></summary>

됩니다. MIT이고, 출처 표기도, 별도 상용 라이선스도, 좌석 수 계산도, 허락받을 사람도 없습니다. 비용을 아끼셨다면 듣고 싶지만, 저희에게 갚을 것은 없습니다.

</details>

<details>
<summary><b>왜 제 주소가 목록에 있나요?</b></summary>

최소 두 번 무언가를 공격하는 중에 관측되었기 때문입니다. [ffraud.com](https://ffraud.com)에서 조회하면 점수와 분류, 쉬운 말로 된 근거를 볼 수 있습니다. 잘못되었거나 그 장비를 이미 정리했다면 [ffraud.com/report](https://ffraud.com/report)로 알려주세요. 다음 빌드에서 다시 확인합니다.

</details>

<details>
<summary><b>큰 유료 서비스들과 뭐가 다른가요?</b></summary>

무료이고, MIT이며, 키도 상한도 없고, 주소마다 왜 등재되었는지 읽을 수 있습니다. 게다가 전체를 내려받을 수 있는데, 대부분의 유료 제품은 얼마를 내도 그건 허락하지 않습니다.

</details>

<details>
<summary><b>단건 조회용 API가 있나요?</b></summary>

있고, 키도 필요 없습니다. 위 섹션이나 [ffraud.com/docs](https://ffraud.com/docs)를 보세요.

</details>

## 함께 만들기

이 데이터베이스는 쓰는 사람들과 함께 자랍니다. 서버나 fail2ban, WAF, 또는 자체 허니팟을 운영한다면 당신을 때린 것을 보내주세요. 저희가 공개합니다. [ffraud.com/report](https://ffraud.com/report)에서 신고하거나, fail2ban을 [바로 쓸 수 있는 엔드포인트](https://ffraud.com/docs/contribute)로 향하게 하거나, 여기에 이슈를 열면 됩니다. 모든 제보를 검증하고 중복을 걸러 점수를 매기며, 확인된 것은 다음 빌드, 즉 30분 안에 반영됩니다. 원하시면 크레딧도 남깁니다.

## 네트워크 목록에 대한 참고

`high-abuse-networks.csv`는 각 네트워크의 주소 중 **저희가 관측한 범위에서** 악성으로 행동한 비율을 나타냅니다. 저희 센서에 닿은 트래픽에 대한 측정이지 어떤 사업자에 대한 법적 판단이 아니며, 고객이 문제를 일으키면 정상적인 호스팅 업체도 올라옵니다. 등재된 네트워크를 운영하는데 측정이 틀렸다고 보신다면 [알려주세요](https://ffraud.com/report). 다음 빌드에서 다시 확인합니다.
