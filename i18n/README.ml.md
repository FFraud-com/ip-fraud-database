# IP തട്ടിപ്പ് ഡാറ്റാബേസ്, ഓരോ 30 മിനിറ്റിലും പുനർനിർമ്മിക്കപ്പെടുന്നു

<p align="center"><b>1,268,837 സ്ഥിരീകരിച്ച ദോഷകരമായ IP വിലാസങ്ങളും 537 ഉയർന്ന ദുരുപയോഗമുള്ള ശൃംഖലകളും. ഓരോ വിലാസത്തിനും സ്കോറും വിഭാഗവുമുണ്ട്, കുറഞ്ഞത് രണ്ടു തവണ സ്വതന്ത്രമായി സ്ഥിരീകരിച്ചിട്ടുമുണ്ട്.</b></p>
<p align="center"><sub>MIT ലൈസൻസ് &middot; രജിസ്ട്രേഷനില്ല, API കീ ഇല്ല, അഭ്യർത്ഥനാ പരിധിയില്ല &middot; പുതുക്കിയത് 12.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/ml.svg?v=1789243201" alt="ffraud.com ൽ തത്സമയ ഡാറ്റാബേസ് കാണുക" width="540"></a></p>

ഇത് [ffraud.com](https://ffraud.com) ന് പിന്നിൽ നിൽക്കുന്ന തുറന്ന IP തട്ടിപ്പ് ഡാറ്റാബേസാണ്. ഇതിലെ ഓരോ വിലാസവും എന്തിനെയോ ആക്രമിക്കുന്നതിനിടെ കണ്ടിട്ടുള്ളതാണ്, കുറഞ്ഞത് രണ്ടു തവണ സ്വതന്ത്രമായി സ്ഥിരീകരിച്ചതാണ്, 0 മുതൽ 100 വരെ സ്കോർ കിട്ടിയതാണ്, എന്തു ചെയ്യുന്നതിനിടെ പിടിക്കപ്പെട്ടു എന്നും ഏതു തരം അടിസ്ഥാനസൗകര്യത്തിലാണ് പ്രവർത്തിക്കുന്നതെന്നും അടയാളപ്പെടുത്തിയതുമാണ്. ആക്രമിക്കുന്നവർ അടിസ്ഥാനസൗകര്യം ഇടതടവില്ലാതെ മാറ്റുന്നു, അതിനാൽ ഒരു തടയൽ പട്ടികയ്ക്ക് അതിന്റെ അവസാന പുതുക്കലിന്റെ വിലയേ ഉള്ളൂ: ഇത് **ഓരോ 30 മിനിറ്റിലും** പ്രവർത്തിക്കുന്ന എൻജിനിൽ നിന്ന് നേരിട്ട് പുനർനിർമ്മിക്കപ്പെടുന്നു. നിങ്ങൾ ഡൗൺലോഡ് ചെയ്യുന്നതുതന്നെയാണ് ഈ നിമിഷം ഇന്റർനെറ്റിനെ ആക്രമിക്കുന്നത്. രജിസ്ട്രേഷനില്ല, കീ ഇല്ല, പരിധിയില്ല. നേരിട്ട് ഒരു ഫയർവാളിലേക്കോ WAF ലേക്കോ രജിസ്ട്രേഷൻ ഫോമിലേക്കോ തട്ടിപ്പ് പരിശോധനാ ശൃംഖലയിലേക്കോ ഒഴിക്കൂ.

## ചുരുക്കത്തിൽ

- **1,268,837** സ്ഥിരീകരിച്ച ദോഷകരമായ IP വിലാസങ്ങൾ, ഓരോന്നും **കുറഞ്ഞത് രണ്ടു തവണ സ്വതന്ത്രമായി** ദുരുപയോഗം ചെയ്യുന്നതിനിടെ കണ്ടിട്ടുള്ളത്
- **537** ശൃംഖലകൾ, അവിടെ ഞങ്ങൾ കണ്ട വിലാസങ്ങൾ ഏറെയും ദോഷകരവും പ്രോക്സി നിറഞ്ഞതുമായിരുന്നു
- **219,617** ഒറ്റത്തവണ ഇമെയിൽ ഡൊമെയ്‌നുകളും ഇതേ ശേഖരത്തിൽ വരുന്നു, അതായത് ഒരിക്കൽ ക്ലോൺ ചെയ്താൽ രജിസ്ട്രേഷൻ പരിശോധനയുടെ രണ്ടു പകുതികളും മൂടപ്പെടും
- ഓരോ വിലാസവും **0 മുതൽ 100 വരെ സ്കോർ**, ഒരു **ഭീഷണി വിഭാഗം**, കാണാൻ കഴിയുമ്പോൾ **അടിസ്ഥാനസൗകര്യത്തിന്റെ തരം** എന്നിവ വഹിക്കുന്നു
- **ഓരോ 30 മിനിറ്റിലും** പുനർനിർമ്മിച്ച് പ്രസിദ്ധീകരിക്കുന്നു. commit ചരിത്രമാണ് മാറ്റങ്ങളുടെ രേഖ, [`metadata.json`](metadata.json) ൽ നിർമ്മാണത്തിന്റെ കൃത്യ സമയമുണ്ട്
- **MIT ലൈസൻസ്**, വാണിജ്യ ഉപയോഗം ഉൾപ്പെടെ, കടപ്പാട് ആവശ്യമില്ല
- ലളിതമായ CSV ഉം TXT ഉം. തുറക്കാൻ ആർക്കൈവില്ല, പഠിക്കാൻ സ്കീമയില്ല, ഇൻസ്റ്റാൾ ചെയ്യാൻ ലൈബ്രറിയില്ല

ഓരോ ഫയലും ഒരു തലക്കെട്ട് വരിയും തുടക്കത്തിൽ ഏതാനും `#` കുറിപ്പുകളുമുള്ള ലളിതമായ വാചകമാണ്. അത് നേരിട്ട് `ipset`, `iptables`, ഒരു WAF നിയമം, അല്ലെങ്കിൽ നിങ്ങൾ ഇപ്പോൾത്തന്നെ ഉപയോഗിക്കുന്ന ഭാഷയിലെ `Set` ലേക്ക് അയക്കൂ.

## ഒന്നും ഡൗൺലോഡ് ചെയ്യാതെ ഒരു വിലാസം പരിശോധിക്കുക

ഒരു കാര്യം പരിശോധിക്കാൻ ഡാറ്റാബേസ് മുഴുവൻ എടുക്കേണ്ടതില്ല. പൊതു API കീ ചോദിക്കുന്നില്ല, ദിവസേനയുള്ള പരിധിയില്ല, ഈ ശേഖരം കൂട്ടത്തോടെ ഉത്തരം നൽകുന്ന അതേ ചോദ്യങ്ങൾക്ക് ഒന്നൊന്നായി ഉത്തരം നൽകുന്നു:

```bash
# ഒരു IP യെക്കുറിച്ചുള്ള പൂർണ്ണ വിവരം: സ്കോർ, കാരണം, വിഭാഗങ്ങൾ
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# ഈ വിലാസം ഒറ്റത്തവണ ഉപയോഗത്തിനുള്ളതാണോ?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# ഈ ഡൊമെയ്ൻ വലിച്ചെറിയാവുന്ന മെയിൽബോക്സുകൾ വിതരണം ചെയ്യുന്നുണ്ടോ?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

ഏജന്റുകൾക്കും സഹായികൾക്കും: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) യന്ത്രങ്ങൾക്കുള്ള സൂചികയാണ്, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) മുഴുവൻ രേഖകളും ശുദ്ധമായ Markdown ആയി സൂക്ഷിക്കുന്നു, [ffraud.com/openapi.json](https://ffraud.com/openapi.json) എന്നത് OpenAPI വിവരണമാണ്. മൂന്നും പൊതുവായതാണ്, കീ ചോദിക്കുന്നില്ല, നേരിട്ട് എടുക്കാൻ വേണ്ടിത്തന്നെ ഉണ്ടാക്കിയതാണ്. പേജ് ഇഷ്ടപ്പെടുന്നവർക്ക് സൗജന്യ പരിശോധനാ ഉപകരണങ്ങൾ [ffraud.com/tools](https://ffraud.com/tools) ൽ ഉണ്ട്.

## ഈ ഡാറ്റാബേസ് എങ്ങനെ പണിയപ്പെടുന്നു

രണ്ടു കാര്യങ്ങളാണ് ഇത് പണിയുന്നത്: ഇടതടവില്ലാതെ ആക്രമിക്കപ്പെടുകയും തന്നെ ആക്രമിക്കുന്നത് എന്താണെന്ന് രേഖപ്പെടുത്തുകയും ചെയ്യുന്ന ഞങ്ങളുടെ സ്വന്തം ഹണിപോട്ട് സെൻസർ ശൃംഖല, പിന്നെ സെർവറുകൾ അടി കൊള്ളുന്നവരുടെ റിപ്പോർട്ടുകൾ. മറ്റൊരാൾ പറഞ്ഞു എന്നതിന്റെ പേരിൽ ഞങ്ങൾ ഒന്നും വീണ്ടും പ്രസിദ്ധീകരിക്കുന്നില്ല. ഇവിടെ പ്രത്യക്ഷപ്പെടുന്നതിനു മുൻപ് ഓരോ വിലാസത്തിനും ffraud എൻജിൻ സ്കോർ നൽകുകയും പരിശോധിക്കുകയും ചെയ്യുന്നു.

പട്ടികയിൽ വരാനുള്ള പരിധി **കുറഞ്ഞത് രണ്ട് സ്വതന്ത്ര സ്ഥിരീകരണങ്ങളാണ്**, കാരണം ഒറ്റത്തവണത്തെ കാഴ്ച വെറും ബഹളമാണ്. ഈ ഒറ്റ നിയമമാണ് ഈ പട്ടികയെ അരിച്ചെടുക്കാത്ത കൂമ്പാരത്തെക്കാൾ ചെറുതും അതിനെക്കാൾ വിലയുള്ളതുമാക്കുന്നത്: ഇതിൽ ശരിക്കും ആക്രമിച്ച വിലാസങ്ങളുണ്ട്, ആരോ എപ്പോഴോ ഒരിക്കൽ അടയാളപ്പെടുത്തിയതെല്ലാം അല്ല.

സ്കോറും വിഭാഗവും അടിസ്ഥാനസൗകര്യ തരവും ഞങ്ങളുടെ സ്വന്തം നിഗമനങ്ങളാണ്, നിങ്ങൾക്ക് വിയോജിക്കാൻ കഴിയേണ്ടതിനാൽ പൂർണ്ണമായി പ്രസിദ്ധീകരിക്കുന്നു. കൃത്യമായ സ്കോറിംഗ് രീതി [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) ൽ വിവരിച്ചിട്ടുണ്ട്.

## പണിയാൻ സഹായിക്കൂ

ഈ ഡാറ്റാബേസ് അത് ഉപയോഗിക്കുന്നവർക്കൊപ്പമാണ് വളരുന്നത്. നിങ്ങൾ സെർവറുകൾ, fail2ban, WAF അല്ലെങ്കിൽ സ്വന്തം ഹണിപോട്ടുകൾ നടത്തുന്നുണ്ടെങ്കിൽ, നിങ്ങളെ ആക്രമിക്കുന്നത് ഞങ്ങൾക്ക് അയക്കൂ, ഞങ്ങളത് പ്രസിദ്ധീകരിക്കാം: [ffraud.com/report](https://ffraud.com/report) ൽ അറിയിക്കുക, fail2ban നെ [തയ്യാറായ എൻഡ്‌പോയിന്റിലേക്ക്](https://ffraud.com/docs/contribute) തിരിക്കുക, അല്ലെങ്കിൽ ഇവിടെത്തന്നെ ഒരു issue തുറക്കുക. ഓരോ സമർപ്പണവും ഞങ്ങൾ പരിശോധിക്കുന്നു, ആവർത്തനങ്ങൾ നീക്കുന്നു, സ്കോർ നൽകുന്നു; സ്ഥിരീകരിച്ചവ അടുത്ത ബിൽഡിൽ, അതായത് അര മണിക്കൂറിനുള്ളിൽ, പുറത്തുവരും, വേണമെങ്കിൽ നിങ്ങളുടെ പേരോടെ.

`high-abuse-networks.csv` ഓരോ ശൃംഖലയുടെയും വിലാസങ്ങളിൽ എത്ര ഭാഗം **ഞങ്ങൾ കണ്ടിടത്തോളം** ദോഷകരമായി പെരുമാറുന്നതായി കണ്ടു എന്ന് അറിയിക്കുന്നു. ഇത് ഞങ്ങളുടെ സെൻസറുകളിൽ എത്തിയ ട്രാഫിക്കിന്റെ അളവാണ്, ഏതെങ്കിലും ഓപ്പറേറ്ററെക്കുറിച്ചുള്ള നിയമപരമായ വിധിയല്ല, ഉപഭോക്താക്കൾ മോശമായി പെരുമാറുമ്പോൾ സത്യസന്ധമായ ഹോസ്റ്റിംഗ് കമ്പനികളും അതിൽ വരും. പട്ടികയിലുള്ള ഒരു ശൃംഖല നിങ്ങൾ നടത്തുന്നുണ്ടെങ്കിൽ അളവ് തെറ്റാണെന്ന് തോന്നുന്നെങ്കിൽ, [ഞങ്ങളോട് പറയൂ](https://ffraud.com/report), അടുത്ത ബിൽഡിൽ വീണ്ടും പരിശോധിക്കാം.
