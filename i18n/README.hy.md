# IP խարդախության շտեմարան, վերակառուցվում է ամեն 30 րոպեն մեկ

<p align="center"><b>1,229,125 հաստատված վնասաբեր IP հասցե և 553 բարձր չարաշահման ցանց։ Յուրաքանչյուր հասցե ունի միավոր, կարգ և առնվազն երկու անկախ հաստատում։</b></p>
<p align="center"><sub>MIT արտոնագիր &middot; առանց գրանցման, առանց API բանալու, առանց հարցումների սահմանի &middot; թարմացվել է 07.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/hy.svg?v=1788786001" alt="Տեսեք կենդանի շտեմարանը ffraud.com-ում" width="540"></a></p>

Սա [ffraud.com](https://ffraud.com)-ի հետևում կանգնած բաց IP խարդախության շտեմարանն է։ Դրա մեջ յուրաքանչյուր հասցե նկատվել է ինչ-որ բանի վրա հարձակվելիս, հաստատվել է առնվազն երկու անգամ անկախ կերպով, ստացել է միավոր 0-ից 100, և նշվել է, թե ինչի վրա է բռնվել ու ինչպիսի ենթակառուցվածքի վրա է աշխատում։ Հարձակվողներն անդադար փոխում են ենթակառուցվածքը, ուստի արգելափակման ցանկն արժե ճիշտ այնքան, որքան իր վերջին թարմացումը. այս մեկը **ամեն 30 րոպեն մեկ** վերակառուցվում է ուղղակիորեն աշխատող շարժիչից։ Այն, ինչ ներբեռնում եք, հենց այս պահին հարձակվում է համացանցի վրա։ Առանց գրանցման, առանց բանալու, առանց սահմանների։ Լցրեք ուղիղ պատնեշի, WAF-ի, գրանցման ձևի կամ խարդախության ստուգման հոսքի մեջ։

## Համառոտ

- **1,229,125** հաստատված վնասաբեր IP հասցե, յուրաքանչյուրը **առնվազն երկու անգամ անկախ կերպով** նկատվել է չարաշահման պահին
- **553** ցանց, որտեղ մեր դիտարկած հասցեները հիմնականում վնասաբեր էին և պրոքսիով լի
- **219,465** մեկանգամյա էլփոստի տիրույթ նույնպես գալիս է այս պահոցում, այսինքն՝ մեկ կլոնավորումը ծածկում է գրանցման ստուգման երկու կեսն էլ
- Յուրաքանչյուր հասցե կրում է **միավոր 0-ից 100**, **սպառնալիքի կարգ** և, երբ տեսանելի է, **ենթակառուցվածքի տեսակը**
- **Ամեն 30 րոպեն մեկ** վերակառուցվում և հրապարակվում է։ Commit-ների պատմությունը փոփոխությունների գրանցամատյանն է, իսկ [`metadata.json`](metadata.json)-ը կրում է կառուցման ճշգրիտ ժամանակը
- **MIT արտոնագիր**, ներառյալ առևտրային օգտագործումը, հեղինակի նշում չի պահանջվում
- Պարզ CSV և TXT։ Բացելու արխիվ չկա, սովորելու սխեմա չկա, տեղադրելու գրադարան չկա

## Ինչ է ասում յուրաքանչյուր տող

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| Դաշտ | Ինչ է ասում |
|------|------|
| `ip` | Հասցեն։ Հանդիպում են և՛ IPv4, և՛ IPv6 |
| `ffraud_score` | Մեր սեփական խարդախության միավորը 0-ից 100։ Այստեղ հրապարակվող ամեն ինչ 50 և ավելի է |
| `confirmations` | Քանի անգամ ենք անկախ կերպով դիտարկել չարաշահումը։ 2-ից ցածրով ոչինչ չի ցուցակագրվում. ամենավատ հասցեները հասնում են 30-40-ի |
| `category` | Ինչի վրա է բռնվել՝ `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` կամ `abuse` |
| `type` | Դրա հետևում գտնվող ենթակառուցվածքը, երբ տեսանելի է՝ `proxy`, `vpn`, `tor`, `datacenter`, `mobile`։ Դատարկ, երբ չենք կարողանում տարբերել |

## Արագ մեկնարկ

```bash
# Հաստատված վնասաբեր IP, կարգով և տեսակով
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# Ամենավատ ցանցերը
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# Մեկանգամյա էլփոստի տիրույթներ
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

Յուրաքանչյուր ֆայլ պարզ տեքստ է՝ վերնագրի տողով և սկզբում մի քանի `#` մեկնաբանությամբ։ Ուղարկեք այն ուղիղ `ipset`, `iptables`, WAF-ի կանոն կամ `Set` այն լեզվում, որն այսպես թե այնպես օգտագործում եք։

## Ստուգեք մեկ հասցե՝ առանց որևէ բան ներբեռնելու

Մեկ բան ստուգելու համար ամբողջ շտեմարանը վերցնելու կարիք չկա։ Հանրային API-ն բանալի չի պահանջում, օրական սահման չունի և մեկ առ մեկ պատասխանում է հենց այն հարցերին, որոնց այս պահոցը զանգվածաբար է պատասխանում.

```bash
# Ամբողջական տեղեկություն մեկ IP-ի մասին՝ միավոր, պատճառ, կարգեր
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Այս հասցեն մեկանգամյա՞ է
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Այս տիրույթը բաժանո՞ւմ է դեն նետվող փոստարկղեր
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Գործակալների և օգնականների համար՝ [ffraud.com/llms.txt](https://ffraud.com/llms.txt)-ը մեքենաների ցուցիչն է, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt)-ը պահում է ողջ փաստաթղթերը մաքուր Markdown-ով, իսկ [ffraud.com/openapi.json](https://ffraud.com/openapi.json)-ը OpenAPI բնութագիրն է։ Երեքն էլ հանրային են, բանալի չեն պահանջում և ստեղծված են ուղղակի վերցնելու համար։ Ովքեր էջն են նախընտրում, անվճար ստուգիչները [ffraud.com/tools](https://ffraud.com/tools) հասցեում են։

## Ինչպես է կառուցվում շտեմարանը

Երկու բան է այն կառուցում՝ մեր սեփական մեղրաթակարդների սենսորային ցանցը, որին անդադար հարձակվում են և որը գրանցում է, թե ինչն է հարձակվում իր վրա, և այն մարդկանց հաղորդումները, ում սերվերները հարվածներ են ստանում։ Ուրիշի խոսքով ոչինչ չենք վերահրապարակում։ Յուրաքանչյուր հասցեին ffraud շարժիչը միավոր է տալիս և ստուգում է, նախքան այն այստեղ հայտնվելը։

Ցանկում հայտնվելու շեմը **երկու կամ ավելի անկախ հաստատում** է, քանի որ մեկ անգամ տեսնելը պարզապես աղմուկ է։ Հենց այս մեկ կանոնն է ցանկը դարձնում չզտված կույտից կարճ և դրանից ավելի արժեքավոր. դրանում այն հասցեներն են, որոնք իսկապես հարձակվում էին, և ոչ թե ամեն ինչ, ինչ որևէ մեկը երբևէ մեկ անգամ նշել է։

Միավորը, կարգը և ենթակառուցվածքի տեսակը մեր սեփական եզրակացություններն են, հրապարակվում են ամբողջությամբ, որպեսզի կարողանաք առարկել դրանց։ Միավորի հաշվարկի ճշգրիտ եղանակը նկարագրված է [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology)-ում։

## Օգնեք կառուցել

Այս շտեմարանն աճում է նրանց հետ, ովքեր օգտագործում են այն։ Եթե սերվերներ, fail2ban, WAF կամ ձեր սեփական մեղրաթակարդներն եք վարում, ուղարկեք մեզ այն, ինչը հարձակվում է ձեզ վրա, և մենք կհրապարակենք՝ հայտնեք [ffraud.com/report](https://ffraud.com/report)-ում, ուղղեք fail2ban-ը [պատրաստի ծայրակետին](https://ffraud.com/docs/contribute), կամ բացեք issue այստեղ։ Յուրաքանչյուր ուղարկվածը ստուգում ենք, կրկնությունները հեռացնում և միավոր տալիս. հաստատվածը դուրս է գալիս հաջորդ կառուցման ժամանակ, այսինքն՝ կես ժամվա ընթացքում, ցանկության դեպքում ձեր անունով։

## Նշում ցանցերի ցանկի մասին

`high-abuse-networks.csv`-ը ցույց է տալիս, թե յուրաքանչյուր ցանցի հասցեների որ մասն ենք **մենք դիտարկել** վնասաբեր վարքագծի մեջ։ Սա մեր սենսորներին հասած երթևեկի չափում է, և ոչ թե իրավական դատավճիռ որևէ օպերատորի վերաբերյալ, և բարեխիղճ հոսթինգ ընկերությունները նույնպես հայտնվում են դրանում, երբ իրենց հաճախորդները վատ են վարվում։ Եթե վարում եք ցանկում ընդգրկված ցանց և չափումը սխալ եք համարում, [ասեք մեզ](https://ffraud.com/report), և հաջորդ կառուցման ժամանակ նորից կստուգենք։
