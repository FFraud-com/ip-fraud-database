# IP saxtakarlıq bazası, hər 30 dəqiqədən bir yenidən qurulur

<p align="center"><b>1 239 601 təsdiqlənmiş zərərli IP ünvanı və 553 yüksək sui-istifadəli şəbəkə. Hər ünvan qiymətləndirilib, kateqoriyalaşdırılıb və ən azı iki dəfə müstəqil təsdiqlənib.</b></p>
<p align="center"><sub>MIT lisenziyası &middot; qeydiyyatsız, API açarısız, sorğu limitisiz &middot; yeniləndi 08.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/az.svg?v=1788892210" alt="Canlı bazaya ffraud.com-da baxın" width="540"></a></p>

Bu, [ffraud.com](https://ffraud.com) arxasında duran açıq IP saxtakarlıq bazasıdır. İçindəki hər ünvan nəyəsə hücum edərkən müşahidə olunub, ən azı iki dəfə müstəqil təsdiqlənib, 0-dan 100-ə qədər qiymətləndirilib və nə edərkən tutulduğu ilə hansı infrastrukturda işlədiyi qeyd olunub. Hücum edənlər infrastrukturunu dayanmadan dəyişir, ona görə bloklama siyahısı yalnız son yenilənməsi qədər dəyərlidir: bu siyahı **hər 30 dəqiqədən bir** birbaşa işləyən mühərrikdən yenidən qurulur. Yüklədiyiniz şey elə indi internetə hücum edəndir. Qeydiyyatsız, açarsız, limitsiz. Birbaşa təhlükəsizlik divarına, WAF-a, qeydiyyat formasına və ya saxtakarlıq yoxlama xəttinə tökün.

## Qısaca

- **1 239 601** təsdiqlənmiş zərərli IP ünvanı, hər biri **iki və ya daha çox dəfə müstəqil şəkildə** sui-istifadə edərkən müşahidə olunub
- **553** şəbəkə, orada müşahidə etdiyimiz ünvanlar əsasən zərərli və proksi ilə dolu idi
- **219 506** birdəfəlik e-poçt domeni də bu deponun içindədir, yəni bir dəfə klonlamaq qeydiyyat yoxlamasının hər iki yarısını əhatə edir
- Hər ünvan **0-dan 100-ə qədər bal**, bir **təhlükə kateqoriyası** və görünəndə **infrastruktur növü** daşıyır
- **Hər 30 dəqiqədən bir** yenidən qurulub yayımlanır. Commit tarixçəsi dəyişikliklərin qeydidir, [`metadata.json`](metadata.json) isə dəqiq yığım vaxtını daşıyır
- **MIT lisenziyası**, kommersiya istifadəsi daxil, mənbə göstərmək tələb olunmur
- Sadə CSV və TXT. Açılası arxiv, öyrəniləsi sxem, quraşdırılası kitabxana yoxdur

## Hər sətir nə deyir

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| Sahə | Nə deyir |
|------|------|
| `ip` | Ünvan. Həm IPv4, həm IPv6 rast gəlinir |
| `ffraud_score` | Öz saxtakarlıq balımız, 0-dan 100-ə. Burada dərc olunan hər şey 50 və yuxarıdır |
| `confirmations` | Sui-istifadəni neçə dəfə müstəqil müşahidə etmişik. 2-dən aşağı heç nə siyahıya düşmür; ən pis ünvanlar 30-40-a çatır |
| `category` | Nə edərkən tutulub: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` və ya `abuse` |
| `type` | Görünəndə arxasındakı infrastruktur: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. Ayırd edə bilmədikdə boş |

## Sürətli başlanğıc

```bash
# Təsdiqlənmiş zərərli IP-lər, kateqoriya və növ ilə
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# Ən pis şəbəkələr
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# Birdəfəlik e-poçt domenləri
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

Hər fayl bir başlıq sətri və əvvəldə bir neçə `#` şərhi olan sadə mətndir. Onu birbaşa `ipset`, `iptables`, WAF qaydası və ya onsuz da işlətdiyiniz dildəki `Set` içinə göndərin.

## Heç nə yükləmədən bir ünvanı yoxlayın

Bir şeyi yoxlamaq üçün bütün bazanı götürmək lazım deyil. İctimai API açar istəmir, gündəlik həddi yoxdur və bu deponun toplu cavab verdiyi eyni suallara bir-bir cavab verir:

```bash
# Bir IP haqqında tam məlumat: bal, səbəb, kateqoriyalar
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Bu ünvan birdəfəlikdir?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Bu domen atılası poçt qutuları paylayır?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Agentlər və köməkçilər üçün: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) maşınlar üçün göstəricidir, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) bütün sənədləri sadə Markdown kimi saxlayır, [ffraud.com/openapi.json](https://ffraud.com/openapi.json) isə OpenAPI spesifikasiyasıdır. Hər üçü açıqdır, açar istəmir və birbaşa götürülmək üçün hazırlanıb. Səhifəni üstün tutanlar üçün pulsuz yoxlayıcılar [ffraud.com/tools](https://ffraud.com/tools) ünvanındadır.

## Baza necə qurulur

Onu iki şey qurur: fasiləsiz hücuma məruz qalan və ona nəyin hücum etdiyini qeyd edən öz bal tələsi sensor şəbəkəmiz və serverləri zərbə alan insanların bildirişləri. Heç nəyi başqasının sözü ilə yenidən dərc etmirik. Hər ünvan burada görünməzdən əvvəl ffraud mühərriki tərəfindən qiymətləndirilir və yoxlanılır.

Siyahıya düşmə həddi **iki və daha çox müstəqil təsdiqdir**, çünki tək müşahidə sadəcə səs-küydür. Məhz bu bir qayda siyahını süzülməmiş yığından qısa və ondan daha dəyərli edir: içində həqiqətən hücum edən ünvanlar var, kiminsə bir dəfə işarələdiyi hər şey deyil.

Bal, kateqoriya və infrastruktur növü bizim öz nəticələrimizdir, etiraz edə biləsiniz deyə tam dərc olunur. Dəqiq qiymətləndirmə üsulu [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) ünvanında yazılıb.

## Qurmağa kömək edin

Bu baza ondan istifadə edənlərlə birlikdə böyüyür. Serverlər, fail2ban, WAF və ya öz bal tələlərinizi idarə edirsinizsə, sizə hücum edəni bizə göndərin, biz onu dərc edək: [ffraud.com/report](https://ffraud.com/report) ünvanında bildirin, fail2ban-ı [hazır son nöqtəyə](https://ffraud.com/docs/contribute) yönəldin və ya burada issue açın. Hər göndərişi yoxlayır, təkrarları çıxarır və qiymətləndiririk; təsdiqlənən növbəti yığımda, yəni yarım saat ərzində, yayımlanır, istəsəniz adınızla birlikdə.

## Şəbəkə siyahısı haqqında qeyd

`high-abuse-networks.csv` hər şəbəkənin ünvanlarının nə qədər hissəsini **bizim müşahidə etdiyimiz qədəri ilə** zərərli davranarkən gördüyümüzü bildirir. Bu, sensorlarımıza çatan trafikin ölçüsüdür, hər hansı operator barədə hüquqi hökm deyil və müştəriləri pis davrananda vicdanlı hostinq şirkətləri də ora düşür. Siyahıdakı şəbəkəni idarə edirsinizsə və ölçünü səhv sayırsınızsa, [bizə bildirin](https://ffraud.com/report), növbəti yığımda yenidən yoxlayaq.
