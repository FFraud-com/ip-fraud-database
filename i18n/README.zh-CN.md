# IP 欺诈数据库，每 30 分钟重建一次

<p align="center"><b>1,258,077 个已确认的恶意 IP 地址，553 个高滥用网络。每个地址都有评分、分类，并至少经过两次独立确认。</b></p>
<p align="center"><sub>MIT 许可 &middot; 无需注册、无需密钥、没有速率限制 &middot; 更新于 11.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/zh-CN.svg?v=1789092001" alt="在 ffraud.com 上浏览实时数据库" width="540"></a></p>

这是 [ffraud.com](https://ffraud.com) 背后的开放 IP 欺诈数据库。里面的每一个地址都是被观测到正在攻击某个目标的，至少经过两次独立确认，按 0 到 100 打分，并标注了它被抓到在做什么、跑在什么样的基础设施上。攻击者会不停更换基础设施，所以一份封禁名单的价值只等于它最后一次更新：这份名单**每 30 分钟**直接从在线引擎重建一次。你下载到的，就是此刻正在攻击互联网的东西。无需注册、无需密钥、没有速率限制。直接丢进防火墙、WAF、注册表单或风控流程即可。

## 关键数字

- **1,258,077** 个已确认的恶意 IP 地址，每一个都被**两次或以上独立观测**到在实施滥用
- **553** 个网络，我们观测到其中的地址绝大多数是恶意的、且代理占比极高
- **219,575** 个一次性邮箱域名也随本仓库一起发布，克隆一次就覆盖了注册风控的两半
- 每个地址都带有 **0 到 100 的评分**、**威胁分类**，以及能看出来时的**基础设施类型**
- **每 30 分钟**重建并推送一次。提交历史就是变更日志，[`metadata.json`](metadata.json) 记录了精确的构建时间
- **MIT 许可**，包含商业用途，无需署名
- 纯粹的 CSV 和 TXT。没有压缩包要解、没有 schema 要学、没有客户端库要装

## 每一行告诉你什么

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| 字段 | 含义 |
|------|------|
| `ip` | 地址本身。IPv4 与 IPv6 都会出现 |
| `ffraud_score` | 我们自己的 0 到 100 欺诈评分。这里发布的一律在 50 及以上 |
| `confirmations` | 我们独立观测到该滥用行为的次数。低于 2 次一律不收录；最糟的地址达到 30 到 40 |
| `category` | 它被抓到在做什么：`c2`、`malware`、`botnet`、`brute_force`、`web_attack`、`scanner`、`phishing`、`spam` 或 `abuse` |
| `type` | 能看出来时它背后的基础设施：`proxy`、`vpn`、`tor`、`datacenter`、`mobile`。判断不出来时留空 |

## 快速开始

```bash
# 已确认的恶意 IP，含分类与类型
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# 最糟糕的网络
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# 一次性邮箱域名
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

每个文件都是纯文本，带一行表头和几行开头的 `#` 注释。可以直接喂给 `ipset`、`iptables`、WAF 规则，或者你本来就在用的那门语言里的 `Set`。

## 不下载也能查单个地址

查一个东西不必把整个数据库拉下来。公开 API 无需密钥、没有每日上限，逐条回答的正是本仓库批量回答的那些问题：

```bash
# 单个 IP 的完整情报：评分、原因、分类
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# 这个邮箱是一次性的吗？
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# 这个域名是否在派发临时邮箱？
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

面向 AI 智能体与助手：[ffraud.com/llms.txt](https://ffraud.com/llms.txt) 是机器可读索引，[ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) 是全部文档的纯 Markdown 版本，[ffraud.com/openapi.json](https://ffraud.com/openapi.json) 是 OpenAPI 规范。三者均为公开资源，无需密钥，可直接抓取。习惯用网页的用户可以使用 [ffraud.com/tools](https://ffraud.com/tools) 上的免费检测工具。

## 这个数据库是怎么建起来的

两样东西支撑着它：我们自己的蜜罐传感器网络，它持续遭受攻击并记录下是谁在攻击；以及那些服务器正在挨打的人发来的举报。我们从不因为别人一句话就转发布任何东西。每个地址在出现在这里之前，都由 ffraud 引擎评过分、验证过。

收录门槛是**两次或以上的独立确认**，因为单次目击只是噪声。正是这一条规则让这份名单比未经筛选的堆砌更小、也更值钱：它收录的是真正在攻击的地址，而不是任何人随手标记过一次的一切。

评分、分类和基础设施类型都是我们自己的判断，完整公开，方便你提出异议。具体的评分方法写在 [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology)。

## 常见问题

<details>
<summary><b>实际多久更新一次？</b></summary>

每 30 分钟，从在线引擎重建后推送到这里。不是每晚一次的导出。本仓库的提交列表就是诚实的记录，[`metadata.json`](metadata.json) 里是你手上这份副本的精确 UTC 构建时间。

</details>

<details>
<summary><b>可以用在商业产品里吗？</b></summary>

可以。MIT，无需署名，没有单独的商业许可，不按席位计费，也不用问任何人。如果它帮你省了钱，我们很乐意听到，但你不欠我们什么。

</details>

<details>
<summary><b>我的地址为什么在名单上？</b></summary>

因为它至少两次被观测到在攻击某个目标。在 [ffraud.com](https://ffraud.com) 上查一下就能看到评分、分类和白话原因。如果这是误判，或者那台机器已经清理干净了，到 [ffraud.com/report](https://ffraud.com/report) 告诉我们，下一次构建就会重新核查。

</details>

<details>
<summary><b>这和那些大牌收费产品有什么不同？</b></summary>

它免费、MIT 许可、无需密钥、没有上限，而且每个地址为什么被收录你都能读到。你还可以把整个数据库下载走，而大多数收费产品出多少钱都不让你这么做。

</details>

<details>
<summary><b>有单条查询的 API 吗？</b></summary>

</details>

## 一起来建设

这个数据库靠使用它的人一起长大。如果你在运维服务器、fail2ban、WAF 或自己的蜜罐，把攻击你的东西发给我们，我们就把它公开：在 [ffraud.com/report](https://ffraud.com/report) 上报，把 fail2ban 指向[现成的接口](https://ffraud.com/docs/contribute)，或者在这里开一个 issue。每一份提交我们都会核实、去重并评分，确认无误的会进入下一次构建，也就是半小时之内，需要的话还会署名。

## 关于网络名单的说明

`high-abuse-networks.csv` 给出的是每个网络中**我们观测到**表现恶意的地址所占的比例。这是对到达我们传感器的流量的一次测量，不是对任何运营商的法律判断；当客户行为不端时，正规主机商也会出现在上面。如果你运营的网络被列入而你认为测量有误，[告诉我们](https://ffraud.com/report)，下一次构建我们会重新核查。
