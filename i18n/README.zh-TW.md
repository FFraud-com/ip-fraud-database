# IP 詐騙資料庫，每 30 分鐘重建一次

<p align="center"><b>1,263,349 個已確認的惡意 IP 位址，553 個高濫用網路。每個位址都有評分、分類，並至少經過兩次獨立確認。</b></p>
<p align="center"><sub>MIT 授權 &middot; 免註冊、免金鑰、無流量限制 &middot; 更新於 11.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/zh-TW.svg?v=1789144206" alt="在 ffraud.com 上瀏覽即時資料庫" width="540"></a></p>

這是 [ffraud.com](https://ffraud.com) 背後的開放 IP 詐騙資料庫。裡面的每一個位址都是被觀測到正在攻擊某個目標的，至少經過兩次獨立確認，以 0 到 100 評分，並標註了它被抓到在做什麼、跑在什麼樣的基礎設施上。攻擊者會不停更換基礎設施，所以一份封鎖名單的價值只等於它最後一次更新：這份名單**每 30 分鐘**直接從線上引擎重建一次。你下載到的，就是此刻正在攻擊網際網路的東西。免註冊、免金鑰、無流量限制。直接丟進防火牆、WAF、註冊表單或風控流程即可。

## 關鍵數字

- **1,263,349** 個已確認的惡意 IP 位址，每一個都被**兩次以上獨立觀測**到正在濫用
- **553** 個網路，我們觀測到其中的位址絕大多數是惡意的、且代理占比極高
- **219,575** 個拋棄式信箱網域也隨本倉庫一起發布，複製一次就涵蓋註冊風控的兩半
- 每個位址都帶有 **0 到 100 的評分**、**威脅分類**，以及看得出來時的**基礎設施類型**
- **每 30 分鐘**重建並推送一次。提交歷史就是變更紀錄，[`metadata.json`](metadata.json) 記錄了精確的建置時間
- **MIT 授權**，包含商業用途，無需署名
- 純粹的 CSV 與 TXT。沒有壓縮檔要解、沒有 schema 要學、沒有用戶端函式庫要裝

## 每一列告訴你什麼

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| 欄位 | 代表什麼 |
|------|------|
| `ip` | 位址本身。IPv4 與 IPv6 都會出現 |
| `ffraud_score` | 我們自己的 0 到 100 詐騙評分。這裡發布的一律在 50 以上 |
| `confirmations` | 我們獨立觀測到該濫用行為的次數。低於 2 次一律不收錄；最糟的位址達到 30 到 40 |
| `category` | 它被抓到在做什麼：`c2`、`malware`、`botnet`、`brute_force`、`web_attack`、`scanner`、`phishing`、`spam` 或 `abuse` |
| `type` | 看得出來時它背後的基礎設施：`proxy`、`vpn`、`tor`、`datacenter`、`mobile`。判斷不出來時留空 |

## 快速開始

```bash
# 已確認的惡意 IP，含分類與類型
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# 最糟糕的網路
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# 拋棄式信箱網域
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

每個檔案都是純文字，帶一行標頭和幾行開頭的 `#` 註解。可以直接餵給 `ipset`、`iptables`、WAF 規則，或你本來就在用的那個語言裡的 `Set`。

## 不用下載也能查單一位址

查一件事不必把整個資料庫拉下來。公開 API 免金鑰、沒有每日上限，逐筆回答的正是本倉庫批量回答的那些問題：

```bash
# 單一 IP 的完整情報：評分、原因、分類
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# 這個信箱是拋棄式的嗎？
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# 這個網域是否在發放臨時信箱？
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

給 AI 代理與助理：[ffraud.com/llms.txt](https://ffraud.com/llms.txt) 是機器可讀索引，[ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) 是全部文件的純 Markdown 版，[ffraud.com/openapi.json](https://ffraud.com/openapi.json) 則是 OpenAPI 規格。三者皆為公開資源，免金鑰，可直接抓取。習慣用網頁的人可以使用 [ffraud.com/tools](https://ffraud.com/tools) 上的免費檢測工具。

## 這個資料庫是怎麼建起來的

兩樣東西撐起它：我們自己的蜜罐感測網路，它持續遭受攻擊並記錄下是誰在攻擊；以及那些伺服器正在挨打的人送來的回報。我們從不因為別人一句話就轉發布任何東西。每個位址在出現在這裡之前，都由 ffraud 引擎評過分、驗證過。

收錄門檻是**兩次以上的獨立確認**，因為單次目擊只是雜訊。正是這一條規則讓這份名單比未經篩選的堆疊更小、也更值錢：它收錄的是真正在攻擊的位址，而不是任何人隨手標記過一次的一切。

評分、分類與基礎設施類型都是我們自己的判斷，完整公開，方便你提出異議。具體的評分方法寫在 [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology)。

</details>

<details>

## 一起來建設

這個資料庫靠使用它的人一起長大。如果你在維運伺服器、fail2ban、WAF 或自己的蜜罐，把攻擊你的東西寄給我們，我們就把它公開：在 [ffraud.com/report](https://ffraud.com/report) 回報，把 fail2ban 指向[現成的端點](https://ffraud.com/docs/contribute)，或在這裡開一個 issue。每一筆提交我們都會查證、去重並評分，確認無誤的會進入下一次建置，也就是半小時之內，需要的話還會署名。

## 關於網路名單的說明

`high-abuse-networks.csv` 給出的是每個網路中**我們觀測到**表現惡意的位址所占的比例。這是對抵達我們感測器的流量的一次量測，不是對任何營運商的法律判斷；當客戶行為不端時，正規主機商也會出現在上面。如果你營運的網路被列入而你認為量測有誤，[告訴我們](https://ffraud.com/report)，下一次建置我們會重新查核。
