# ฐานข้อมูลการฉ้อโกงทาง IP สร้างใหม่ทุก 30 นาที

<p align="center"><b>ที่อยู่ IP อันตรายที่ยืนยันแล้ว 1,249,951 รายการ และเครือข่ายที่ถูกใช้ในทางมิชอบสูง 553 เครือข่าย ทุกที่อยู่มีคะแนน มีหมวดหมู่ และผ่านการยืนยันอย่างเป็นอิสระอย่างน้อยสองครั้ง</b></p>
<p align="center"><sub>สัญญาอนุญาต MIT &middot; ไม่ต้องสมัคร ไม่ต้องใช้คีย์ API ไม่จำกัดจำนวนคำขอ &middot; อัปเดตเมื่อ 10.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/th.svg?v=1789014601" alt="ดูฐานข้อมูลสดบน ffraud.com" width="540"></a></p>

นี่คือฐานข้อมูลการฉ้อโกงทาง IP แบบเปิดที่อยู่เบื้องหลัง [ffraud.com](https://ffraud.com) ทุกที่อยู่ในนี้ถูกสังเกตพบขณะกำลังโจมตีบางอย่าง ผ่านการยืนยันอย่างเป็นอิสระอย่างน้อยสองครั้ง ได้คะแนนจาก 0 ถึง 100 และติดป้ายว่าถูกจับได้ว่าทำอะไรและทำงานอยู่บนโครงสร้างพื้นฐานแบบไหน ผู้โจมตีเปลี่ยนโครงสร้างพื้นฐานอยู่ตลอด รายการบล็อกจึงมีค่าเท่ากับการอัปเดตครั้งล่าสุดของมันเท่านั้น รายการนี้ถูกสร้างใหม่**ทุก 30 นาที**ตรงจากเอนจินที่ทำงานอยู่จริง สิ่งที่คุณดาวน์โหลดคือสิ่งที่กำลังโจมตีอินเทอร์เน็ตอยู่ในขณะนี้ ไม่ต้องสมัคร ไม่ต้องใช้คีย์ ไม่มีขีดจำกัด ใส่ลงไฟร์วอลล์ WAF ฟอร์มสมัครสมาชิก หรือสายงานตรวจจับการฉ้อโกงได้ทันที

## สรุปตัวเลข

- ที่อยู่ IP อันตรายที่ยืนยันแล้ว **1,249,951** รายการ แต่ละรายการถูกสังเกตพบว่าใช้ในทางมิชอบ **อย่างน้อยสองครั้งโดยอิสระ**
- เครือข่าย **553** แห่ง ที่ที่อยู่ซึ่งเราสังเกตพบส่วนใหญ่เป็นอันตรายและหนาแน่นไปด้วยพร็อกซี
- โดเมนอีเมลใช้แล้วทิ้ง **219,530** รายการก็มาพร้อมกับ repository นี้ด้วย โคลนครั้งเดียวจึงครอบคลุมทั้งสองด้านของการตรวจสอบตอนสมัครสมาชิก
- ทุกที่อยู่มี **คะแนน 0 ถึง 100** มี **หมวดหมู่ภัยคุกคาม** และมี **ประเภทโครงสร้างพื้นฐาน** เมื่อมองเห็นได้
- สร้างใหม่และเผยแพร่**ทุก 30 นาที** ประวัติ commit คือบันทึกการเปลี่ยนแปลง และ [`metadata.json`](metadata.json) เก็บเวลาสร้างที่แม่นยำไว้
- **สัญญาอนุญาต MIT** รวมการใช้เชิงพาณิชย์ ไม่ต้องให้เครดิต
- เป็น CSV และ TXT ธรรมดา ไม่มีไฟล์บีบอัดให้แตก ไม่มีสคีมาให้เรียน ไม่มีไลบรารีให้ติดตั้ง

## แต่ละแถวบอกอะไร

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| ฟิลด์ | บอกอะไร |
|------|------|
| `ip` | ที่อยู่ ปรากฏทั้ง IPv4 และ IPv6 |
| `ffraud_score` | คะแนนการฉ้อโกงของเราเอง 0 ถึง 100 ทุกอย่างที่เผยแพร่ที่นี่อยู่ที่ 50 ขึ้นไป |
| `confirmations` | จำนวนครั้งที่เราสังเกตพบการใช้ในทางมิชอบอย่างเป็นอิสระ ต่ำกว่า 2 ไม่ถูกบรรจุ ที่อยู่ที่แย่ที่สุดขึ้นไปถึง 30 ถึง 40 |
| `category` | ถูกจับได้ว่าทำอะไร: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` หรือ `abuse` |
| `type` | โครงสร้างพื้นฐานเบื้องหลังเมื่อมองเห็น: `proxy`, `vpn`, `tor`, `datacenter`, `mobile` เว้นว่างเมื่อเราแยกไม่ออก |

## เริ่มใช้อย่างรวดเร็ว

```bash
# IP อันตรายที่ยืนยันแล้ว พร้อมหมวดหมู่และประเภท
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# เครือข่ายที่แย่ที่สุด
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# โดเมนอีเมลใช้แล้วทิ้ง
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

ทุกไฟล์เป็นข้อความล้วน มีบรรทัดหัวตารางและคอมเมนต์ `#` อยู่ไม่กี่บรรทัดตอนต้น ส่งต่อเข้า `ipset`, `iptables`, กฎ WAF หรือ `Set` ในภาษาที่คุณใช้อยู่แล้วได้ทันที

## ตรวจสอบทีละที่อยู่โดยไม่ต้องดาวน์โหลดอะไรเลย

คุณไม่จำเป็นต้องดึงฐานข้อมูลทั้งก้อนเพื่อตรวจสอบเรื่องเดียว API สาธารณะไม่ต้องใช้คีย์ ไม่มีเพดานต่อวัน และตอบทีละรายการในคำถามเดียวกับที่ repository นี้ตอบแบบยกชุด:

```bash
# ข้อมูลครบถ้วนของ IP หนึ่งหมายเลข: คะแนน เหตุผล หมวดหมู่
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# ที่อยู่นี้เป็นแบบใช้แล้วทิ้งหรือไม่
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# โดเมนนี้แจกกล่องจดหมายใช้แล้วทิ้งหรือเปล่า
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

สำหรับเอเจนต์และผู้ช่วยอัตโนมัติ: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) คือดัชนีสำหรับเครื่อง, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) คือเอกสารทั้งหมดในรูป Markdown ล้วน และ [ffraud.com/openapi.json](https://ffraud.com/openapi.json) คือข้อกำหนด OpenAPI ทั้งสามอย่างเปิดสาธารณะ ไม่ต้องใช้คีย์ และทำมาเพื่อให้ดึงไปใช้ได้โดยตรง ใครถนัดหน้าเว็บมากกว่า ใช้เครื่องมือตรวจสอบฟรีได้ที่ [ffraud.com/tools](https://ffraud.com/tools)

## ฐานข้อมูลนี้สร้างขึ้นอย่างไร

สองสิ่งเป็นตัวสร้างมันขึ้นมา: เครือข่ายเซนเซอร์ honeypot ของเราเอง ซึ่งถูกโจมตีอย่างต่อเนื่องและบันทึกว่าอะไรกำลังโจมตีมัน กับรายงานจากคนที่เซิร์ฟเวอร์ของตัวเองกำลังถูกถล่ม เราไม่เผยแพร่ซ้ำสิ่งใดเพียงเพราะคนอื่นบอกมา ทุกที่อยู่ได้รับคะแนนและผ่านการตรวจสอบจากเอนจิน ffraud ก่อนจะมาปรากฏที่นี่

เกณฑ์ในการถูกบรรจุคือ **การยืนยันอย่างเป็นอิสระตั้งแต่สองครั้งขึ้นไป** เพราะการพบเห็นเพียงครั้งเดียวคือสัญญาณรบกวน กฎข้อเดียวนี้เองที่ทำให้รายการนี้สั้นกว่ากองข้อมูลที่ไม่ผ่านการกรอง และมีค่ามากกว่า: ในนั้นคือที่อยู่ที่โจมตีจริง ไม่ใช่ทุกอย่างที่ใครสักคนเคยติดธงไว้ครั้งหนึ่ง

คะแนน หมวดหมู่ และประเภทโครงสร้างพื้นฐานเป็นข้อสรุปของเราเอง เผยแพร่ครบถ้วนเพื่อให้คุณโต้แย้งได้ วิธีให้คะแนนที่แน่ชัดอธิบายไว้ที่ [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology)

## มาช่วยกันสร้าง

ฐานข้อมูลนี้เติบโตไปพร้อมกับคนที่ใช้มัน ถ้าคุณดูแลเซิร์ฟเวอร์ fail2ban WAF หรือ honeypot ของตัวเอง ส่งสิ่งที่โจมตีคุณมาให้เรา แล้วเราจะเผยแพร่ให้: รายงานที่ [ffraud.com/report](https://ffraud.com/report) ชี้ fail2ban ไปที่ [endpoint สำเร็จรูป](https://ffraud.com/docs/contribute) หรือเปิด issue ที่นี่ เราตรวจสอบ ตัดรายการซ้ำ และให้คะแนนทุกรายการที่ส่งเข้ามา สิ่งที่ยืนยันแล้วจะเข้าสู่การสร้างรอบถัดไป คือภายในครึ่งชั่วโมง พร้อมเครดิตชื่อคุณถ้าต้องการ

## หมายเหตุเกี่ยวกับรายชื่อเครือข่าย

`high-abuse-networks.csv` รายงานสัดส่วนของที่อยู่ในแต่ละเครือข่ายที่ **เราสังเกตพบ** ว่ามีพฤติกรรมเป็นอันตราย นี่คือการวัดปริมาณทราฟฟิกที่มาถึงเซนเซอร์ของเรา ไม่ใช่คำตัดสินทางกฎหมายต่อผู้ให้บริการรายใด และผู้ให้บริการโฮสติงที่สุจริตก็ปรากฏอยู่ในนั้นได้เมื่อลูกค้าของเขาประพฤติไม่ดี ถ้าคุณดูแลเครือข่ายที่อยู่ในรายการและเห็นว่าการวัดผิดพลาด [แจ้งเรามา](https://ffraud.com/report) แล้วเราจะตรวจซ้ำในการสร้างรอบถัดไป
