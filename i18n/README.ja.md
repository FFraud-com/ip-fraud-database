# IP不正データベース、30分ごとに再構築

<p align="center"><b>確認済みの悪性IPアドレス 1,249,734 件、高悪用ネットワーク 553 件。すべてにスコアと分類が付き、少なくとも2回は独立して確認されています。</b></p>
<p align="center"><sub>MITライセンス &middot; 登録不要、APIキー不要、レート制限なし &middot; 更新日 10.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/ja.svg?v=1789007408" alt="ffraud.com でライブのデータベースを見る" width="540"></a></p>

[ffraud.com](https://ffraud.com) を支えているオープンなIP不正データベースです。ここにあるアドレスはどれも、何かを攻撃しているところを観測され、少なくとも2回は独立して確認され、0から100でスコア付けされ、何をしていて捕まったのか、どんなインフラで動いているのかまでラベルが付いています。攻撃者はインフラを絶えず入れ替えるので、ブロックリストの価値は最後に更新された時点で決まります。このリストは**30分ごと**に、稼働中のエンジンから直接再構築されます。ダウンロードしたものが、今この瞬間にインターネットを攻撃しているものです。登録不要、APIキー不要、レート制限なし。ファイアウォール、WAF、登録フォーム、不正検知のパイプラインにそのまま投入できます。

## 主要な数字

- **1,249,734** 件の確認済み悪性IPアドレス。それぞれ**2回以上、独立して**悪用が観測されています
- **553** 件のネットワーク。観測したアドレスの大半が悪性で、かつプロキシに偏っていたものです
- **219,530** 件の使い捨てメールドメインも同じリポジトリに入っているので、1回クローンすれば登録時チェックの両面をカバーできます
- すべてのアドレスに **0から100のスコア**、**脅威カテゴリ**、そして判別できる場合は**インフラの種別**が付いています
- **30分ごと**に再構築してプッシュ。コミット履歴がそのまま変更履歴で、[`metadata.json`](metadata.json) に正確なビルド時刻が入っています
- **MITライセンス**、商用利用可、クレジット不要
- 素のCSVとTXT。展開するアーカイブも、覚えるスキーマも、入れるクライアントライブラリもありません

## リポジトリの中身

| ファイル | 行数 | 内容 |
|------|------:|------|
| [`threat-ips/confirmed-abusive.csv`](../threat-ips/confirmed-abusive.csv) | 1,249,734 | 悪性アドレス。それぞれ2回以上確認済みで、0から100のスコア、脅威カテゴリ（c2、マルウェア、ボットネット、ブルートフォース、Web攻撃、スキャナー、フィッシング、スパム）、判明している場合はインフラ種別（proxy、vpn、tor、datacenter、mobile）付き |
| [`asn-reputation/high-abuse-networks.csv`](../asn-reputation/high-abuse-networks.csv) | 553 | 観測したアドレスの大半が悪性かつプロキシに偏っていたネットワーク。防弾ホスティングの特徴です |
| [`disposable-email-domains.txt`](../disposable-email-domains.txt) | 219,530 | 使い捨て・一時利用のメールドメイン。1行に1つ |
| [`ip-intelligence/examples.json`](../ip-intelligence/examples.json) | サンプル | アドレスごとの完全な情報：スコア、平易な言葉での理由、付与したすべてのカテゴリ |
| [`metadata.json`](../metadata.json) | &mdash; | 現在の件数とUTCのビルド時刻。スクリプトが手元のコピーの新しさを判断できます |

## 各行が示していること

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| フィールド | 意味 |
|------|------|
| `ip` | アドレス。IPv4もIPv6も入ります |
| `ffraud_score` | 独自の0から100の不正スコア。ここで公開しているのはすべて50以上です |
| `confirmations` | その悪用を独立して観測した回数。2回未満は掲載しません。最悪のアドレスは30から40に達します |
| `category` | 何をしていて捕まったか：`c2`、`malware`、`botnet`、`brute_force`、`web_attack`、`scanner`、`phishing`、`spam`、`abuse` |
| `type` | 判別できる場合の背後のインフラ：`proxy`、`vpn`、`tor`、`datacenter`、`mobile`。判別できないときは空欄です |

## クイックスタート

```bash
# 確認済みの悪性IP、カテゴリと種別付き
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# 最悪のネットワーク
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# 使い捨てメールドメイン
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

どのファイルもヘッダー行と先頭のいくつかの `#` コメントが付いた素のテキストです。`ipset`、`iptables`、WAFのルール、あるいは普段使っている言語の `Set` にそのまま流し込めます。

## ダウンロードせずに1件だけ調べる

1件調べるためにデータベース全体を取る必要はありません。公開APIはキー不要、1日の上限もなく、このリポジトリが一括で答えているのと同じ問いに1件ずつ答えます。

```bash
# 1つのIPの完全な情報：スコア、理由、カテゴリ
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# このアドレスは使い捨てか？
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# このドメインは使い捨てメールボックスを配っているか？
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

エージェントやアシスタント向け：[ffraud.com/llms.txt](https://ffraud.com/llms.txt) が機械可読インデックス、[ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) が全ドキュメントのプレーンなMarkdown、[ffraud.com/openapi.json](https://ffraud.com/openapi.json) がOpenAPI仕様です。3つとも公開されており、キー不要で、直接取得されることを前提にしています。ページで確認したい方は [ffraud.com/tools](https://ffraud.com/tools) の無料チェッカーをどうぞ。

## このデータベースの作り方

2つのものが土台です。絶えず攻撃を受け、何が攻撃してきたかを記録している自前のハニーポット観測網と、実際にサーバーを叩かれている人たちからの報告です。他人の言葉を鵜呑みにして再公開することはありません。どのアドレスも、ここに載る前に ffraud エンジンがスコアを付け、検証しています。

掲載の基準は**2回以上の独立した確認**です。1回の目撃はノイズにすぎません。このルール1つのおかげで、この一覧は無選別の寄せ集めより小さく、そして価値があります。本当に攻撃していたアドレスだけが入っていて、誰かが一度フラグを立てただけのものは入っていません。

スコアも、カテゴリも、インフラ種別も、私たちの判断です。反論できるように全部公開しています。スコアリングの具体的な方法は [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) に書いてあります。

## よくある質問

<details>
<summary><b>実際にどのくらいの頻度で更新されますか？</b></summary>

30分ごとです。稼働中のエンジンから再構築してここにプッシュしています。夜間バッチではありません。このリポジトリのコミット一覧が正直な記録で、[`metadata.json`](metadata.json) に手元のコピーの正確なUTCビルド時刻が入っています。

</details>

<details>
<summary><b>商用製品で使えますか？</b></summary>

使えます。MITで、クレジット不要、別途の商用ライセンスもなく、シート数の勘定もなく、誰かに許可を取る必要もありません。コスト削減になったなら聞かせてもらえると嬉しいですが、何も義務はありません。

</details>

<details>
<summary><b>なぜ自分のアドレスが載っているのですか？</b></summary>

少なくとも2回、何かを攻撃しているところが観測されたからです。[ffraud.com](https://ffraud.com) で調べれば、スコア、カテゴリ、平易な言葉での理由が見られます。それが誤りだったり、そのマシンをすでにクリーンにしたのなら、[ffraud.com/report](https://ffraud.com/report) から知らせてください。次のビルドで再確認します。

</details>

<details>
<summary><b>大手の有料サービスと何が違いますか？</b></summary>

無料で、MITライセンスで、キーも上限もなく、どのアドレスがなぜ載っているのかを読めます。しかもデータベース全体をダウンロードできます。ほとんどの有料製品は、いくら払ってもそれを許しません。

</details>

<details>
<summary><b>単発の照会用APIはありますか？</b></summary>

あります。キーも不要です。上のセクション、または [ffraud.com/docs](https://ffraud.com/docs) を見てください。

</details>

## 一緒に育てる

このデータベースは使っている人たちと一緒に育ちます。サーバー、fail2ban、WAF、あるいは自前のハニーポットを運用しているなら、あなたを攻撃してきたものを送ってください。こちらで公開します。[ffraud.com/report](https://ffraud.com/report) から報告する、fail2ban を[そのまま使えるエンドポイント](https://ffraud.com/docs/contribute)に向ける、あるいはここで issue を立てる。すべての投稿を検証し、重複を除き、スコアを付けます。確認できたものは次のビルド、つまり30分以内に反映されます。希望すればクレジットも入ります。

## ネットワーク一覧についての注記

`high-abuse-networks.csv` は、各ネットワークのアドレスのうち**私たちが観測した範囲で**悪性の振る舞いをしたものの割合を示します。これは私たちのセンサーに届いたトラフィックの測定であって、事業者に対する法的な判断ではありません。顧客が問題を起こせば、まっとうなホスティング事業者も載ります。掲載されたネットワークを運用していて測定が誤っていると思われる場合は、[お知らせください](https://ffraud.com/report)。次のビルドで再確認します。
