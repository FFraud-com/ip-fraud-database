# IP თაღლითობის ბაზა, ხელახლა შენდება ყოველ 30 წუთში

<p align="center"><b>1,267,832 დადასტურებულად მავნე IP მისამართი და 537 მაღალი ბოროტად გამოყენების ქსელი. თითოეულ მისამართს აქვს ქულა, კატეგორია და სულ მცირე ორი დამოუკიდებელი დადასტურება.</b></p>
<p align="center"><sub>MIT ლიცენზია &middot; რეგისტრაციის გარეშე, API გასაღების გარეშე, მოთხოვნების ლიმიტის გარეშე &middot; განახლდა 12.09.2026</sub></p>

ეს არის ღია IP თაღლითობის ბაზა, რომელიც [ffraud.com](https://ffraud.com)-ს უდგას უკან. მასში თითოეული მისამართი დაფიქსირდა, როცა რაღაცას თავს ესხმოდა, დადასტურდა სულ მცირე ორჯერ დამოუკიდებლად, მიიღო ქულა 0-დან 100-მდე და მოინიშნა იმით, რაზეც წაასწრეს და რა ტიპის ინფრასტრუქტურაზე მუშაობს. თავდამსხმელები ინფრასტრუქტურას განუწყვეტლივ ცვლიან, ამიტომ ბლოკირების სია ზუსტად იმდენად ღირს, რამდენადაც მისი ბოლო განახლება: ეს სია **ყოველ 30 წუთში** პირდაპირ მომუშავე ძრავიდან შენდება ხელახლა. ის, რასაც ჩამოტვირთავთ, სწორედ ახლა ესხმის თავს ინტერნეტს. რეგისტრაციის გარეშე, გასაღების გარეშე, ლიმიტების გარეშე. ჩაასხით პირდაპირ ბრანდმაუერში, WAF-ში, რეგისტრაციის ფორმაში ან თაღლითობის შემოწმების ხაზში.

## მოკლედ

- **1,267,832** დადასტურებულად მავნე IP მისამართი, თითოეული **სულ მცირე ორჯერ დამოუკიდებლად** დაფიქსირდა ბოროტად გამოყენებისას
- **537** ქსელი, სადაც ჩვენ მიერ დაფიქსირებული მისამართები უპირატესად მავნე და პროქსით სავსე იყო
- **219,610** ერთჯერადი ელფოსტის დომენიც ამავე საცავში მოდის, ანუ ერთი კლონირება რეგისტრაციის შემოწმების ორივე ნახევარს ფარავს
- თითოეულ მისამართს აქვს **ქულა 0-დან 100-მდე**, **საფრთხის კატეგორია** და, თუ ჩანს, **ინფრასტრუქტურის ტიპი**
- **ყოველ 30 წუთში** ხელახლა შენდება და ქვეყნდება. commit-ების ისტორია არის ცვლილებების ჩანაწერი, ხოლო [`metadata.json`](metadata.json) ზუსტ აწყობის დროს ატარებს
- **MIT ლიცენზია**, კომერციული გამოყენების ჩათვლით, ავტორის მითითება არ არის საჭირო
- უბრალო CSV და TXT. გასახსნელი არქივი არ არის, შესასწავლი სქემა არ არის, დასაყენებელი ბიბლიოთეკა არ არის

## რას ამბობს თითოეული სტრიქონი

```csv
ip,ffraud_score,confirmations,category,type

193.46.255.86,95,33,c2,proxy
```

| ველი | რას ამბობს |
|------|------|
| `ip` | მისამართი. გვხვდება როგორც IPv4, ისე IPv6 |
| `ffraud_score` | ჩვენი საკუთარი თაღლითობის ქულა 0-დან 100-მდე. აქ გამოქვეყნებული ყველაფერი 50 და ზემოთაა |
| `confirmations` | რამდენჯერ დავაფიქსირეთ ბოროტად გამოყენება დამოუკიდებლად. 2-ზე ნაკლებით არაფერი შედის სიაში; ყველაზე ცუდი მისამართები 30-40-ს აღწევს |
| `category` | რაზე წაასწრეს: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` ან `abuse` |
| `type` | მის უკან არსებული ინფრასტრუქტურა, როცა ჩანს: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. ცარიელი, როცა ვერ ვარჩევთ |

## შეამოწმეთ ერთი მისამართი არაფრის ჩამოტვირთვის გარეშე

ერთი რამის შესამოწმებლად მთელი ბაზის აღება არ გჭირდებათ. საჯარო API გასაღებს არ ითხოვს, დღიური ზღვარი არ აქვს და სათითაოდ პასუხობს იმავე კითხვებს, რომლებზეც ეს საცავი მასობრივად პასუხობს:

```bash
# სრული ინფორმაცია ერთ IP-ზე: ქულა, მიზეზი, კატეგორიები
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# ეს მისამართი ერთჯერადია?

# ეს დომენი გასაყრელ საფოსტო ყუთებს არიგებს?

```

აგენტებისა და ასისტენტებისთვის: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) მანქანებისთვის განკუთვნილი საძიებელია, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) მთელ დოკუმენტაციას სუფთა Markdown-ად ინახავს, ხოლო [ffraud.com/openapi.json](https://ffraud.com/openapi.json) OpenAPI სპეციფიკაციაა. სამივე საჯაროა, გასაღებს არ ითხოვს და პირდაპირ წამოსაღებადაა გაკეთებული. ვისაც გვერდი ურჩევნია, უფასო შემმოწმებლები [ffraud.com/tools](https://ffraud.com/tools)-ზეა.

## როგორ შენდება ბაზა

მას ორი რამ აშენებს: ჩვენივე თაფლის ხაფანგების სენსორული ქსელი, რომელსაც განუწყვეტლივ ესხმიან თავს და რომელიც აფიქსირებს, რა ესხმის მას, და იმ ადამიანების შეტყობინებები, ვისაც სერვერები უჯდებათ დარტყმის ქვეშ. სხვისი სიტყვით არაფერს ვაქვეყნებთ ხელახლა. თითოეულ მისამართს ffraud-ის ძრავა ქულას აძლევს და ამოწმებს, სანამ აქ გამოჩნდება.

სიაში მოხვედრის ზღვარი არის **ორი ან მეტი დამოუკიდებელი დადასტურება**, რადგან ერთჯერადი დანახვა უბრალოდ ხმაურია. სწორედ ეს ერთი წესი ხდის სიას გაუფილტრავ გროვაზე მოკლედ და მასზე ღირებულად: მასში ის მისამართებია, რომლებიც ნამდვილად ესხმოდნენ თავს, და არა ყველაფერი, რაც ვინმემ ოდესმე ერთხელ მონიშნა.

ქულა, კატეგორია და ინფრასტრუქტურის ტიპი ჩვენივე დასკვნებია, სრულად გამოქვეყნებული, რომ შეძლოთ მათი გაპროტესტება. ქულის დაწერის ზუსტი მეთოდი აღწერილია [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology)-ზე.
