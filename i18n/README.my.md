# IP လိမ်လည်မှု ဒေတာဘေ့စ်၊ မိနစ် ၃၀ တိုင်း ပြန်တည်ဆောက်သည်

<p align="center"><b>အတည်ပြုပြီး အန္တရာယ်ရှိ IP လိပ်စာ 1,253,176 ခုနှင့် အလွဲသုံးစားမှု မြင့်မားသော ကွန်ရက် 553 ခု။ လိပ်စာတိုင်းတွင် အမှတ်၊ အမျိုးအစားရှိပြီး အနည်းဆုံး နှစ်ကြိမ် လွတ်လပ်စွာ အတည်ပြုထားသည်။</b></p>
<p align="center"><sub>MIT လိုင်စင် &middot; မှတ်ပုံတင်စရာမလို၊ API သော့မလို၊ တောင်းဆိုမှု ကန့်သတ်ချက်မရှိ &middot; မွမ်းမံပြီး 10.09.2026</sub></p>

ဤသည်မှာ [ffraud.com](https://ffraud.com) နောက်ကွယ်တွင် ရပ်တည်နေသော ပွင့်လင်း IP လိမ်လည်မှု ဒေတာဘေ့စ်ဖြစ်သည်။ ထဲတွင်ရှိသော လိပ်စာတိုင်းကို တစ်ခုခုကို တိုက်ခိုက်နေစဉ် တွေ့ရှိခဲ့ပြီး၊ အနည်းဆုံး နှစ်ကြိမ် လွတ်လပ်စွာ အတည်ပြုကာ၊ ၀ မှ ၁၀၀ အထိ အမှတ်ပေးပြီး၊ ဘာလုပ်နေစဉ် ဖမ်းမိသည်နှင့် မည်သည့်အခြေခံအဆောက်အအုံပေါ်တွင် လည်ပတ်နေသည်ကို အမှတ်အသားပြုထားသည်။ တိုက်ခိုက်သူများသည် အခြေခံအဆောက်အအုံကို မရပ်မနား ပြောင်းလဲကြသဖြင့် ပိတ်ဆို့စာရင်းတစ်ခု၏ တန်ဖိုးမှာ ၎င်း၏ နောက်ဆုံးမွမ်းမံမှုအတိုင်းသာ ဖြစ်သည်- ဤစာရင်းကို **မိနစ် ၃၀ တိုင်း** လည်ပတ်နေသော အင်ဂျင်မှ တိုက်ရိုက် ပြန်တည်ဆောက်သည်။ သင်ဒေါင်းလုဒ်လုပ်သည့်အရာမှာ ယခုအချိန်တွင် အင်တာနက်ကို တိုက်ခိုက်နေသည့်အရာပင် ဖြစ်သည်။ မှတ်ပုံတင်စရာမလို၊ သော့မလို၊ ကန့်သတ်ချက်မရှိ။ firewall၊ WAF၊ စာရင်းသွင်းပုံစံ သို့မဟုတ် လိမ်လည်မှု စစ်ဆေးလိုင်းထဲသို့ တိုက်ရိုက် ထည့်လိုက်ပါ။

## အကျဉ်းချုပ်

- အတည်ပြုပြီး အန္တရာယ်ရှိ IP လိပ်စာ **1,253,176** ခု၊ တစ်ခုချင်းစီကို **အနည်းဆုံး နှစ်ကြိမ် လွတ်လပ်စွာ** အလွဲသုံးစားနေစဉ် တွေ့ရှိခဲ့သည်
- ကွန်ရက် **553** ခု၊ ထိုနေရာများတွင် ကျွန်ုပ်တို့ တွေ့ရှိသော လိပ်စာများသည် အများစုအားဖြင့် အန္တရာယ်ရှိပြီး ပရောက်စီ ပြည့်နှက်နေသည်
- တစ်ကြိမ်သုံး အီးမေးလ် ဒိုမိန်း **219,530** ခုသည်လည်း ဤသိုလှောင်ရာတွင် ပါဝင်လာသဖြင့် တစ်ကြိမ် clone လုပ်ရုံဖြင့် စာရင်းသွင်းစစ်ဆေးမှု၏ နှစ်ဖက်စလုံးကို လွှမ်းခြုံနိုင်သည်
- လိပ်စာတိုင်းတွင် **၀ မှ ၁၀၀ အမှတ်**၊ **ခြိမ်းခြောက်မှု အမျိုးအစား**နှင့် မြင်နိုင်လျှင် **အခြေခံအဆောက်အအုံ အမျိုးအစား** ပါဝင်သည်
- **မိနစ် ၃၀ တိုင်း** ပြန်တည်ဆောက်ပြီး ထုတ်ဝေသည်။ commit မှတ်တမ်းသည်ပင် ပြောင်းလဲမှု မှတ်တမ်းဖြစ်ပြီး [`metadata.json`](metadata.json) တွင် တည်ဆောက်ချိန် အတိအကျ ပါဝင်သည်
- **MIT လိုင်စင်**၊ စီးပွားဖြစ်သုံးစွဲမှု အပါအဝင်၊ ကျေးဇူးတင်စကား မလိုအပ်ပါ
- ရိုးရိုး CSV နှင့် TXT။ ဖွင့်ရန် archive မရှိ၊ သင်ယူရန် schema မရှိ၊ တပ်ဆင်ရန် library မရှိ

ဖိုင်တိုင်းသည် ခေါင်းစဉ်တစ်ကြောင်းနှင့် အစတွင် `#` မှတ်ချက်အနည်းငယ်ပါသော ရိုးရိုးစာသားဖြစ်သည်။ ၎င်းကို `ipset`၊ `iptables`၊ WAF စည်းမျဉ်း၊ သို့မဟုတ် သင်သုံးနေကျ ဘာသာစကား၏ `Set` ထဲသို့ တိုက်ရိုက် ပို့လိုက်ပါ။

## ဘာမှမဒေါင်းလုဒ်ဘဲ လိပ်စာတစ်ခုကို စစ်ဆေးပါ

တစ်ခုတည်းကို စစ်ဆေးရန် ဒေတာဘေ့စ်တစ်ခုလုံး ယူစရာမလိုပါ။ အများပြည်သူသုံး API သည် သော့မတောင်းဘဲ နေ့စဉ်ကန့်သတ်ချက်လည်း မရှိပါ၊ ဤသိုလှောင်ရာက အစုလိုက် ဖြေဆိုသော မေးခွန်းများကိုပင် တစ်ခုချင်း ဖြေဆိုပေးသည်-

```bash
# IP တစ်ခုအတွက် အပြည့်အစုံ အချက်အလက်- အမှတ်၊ အကြောင်းရင်း၊ အမျိုးအစားများ
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# ဒီလိပ်စာက တစ်ကြိမ်သုံးလား
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# ဒီဒိုမိန်းက စွန့်ပစ်စာတိုက်ပုံးတွေ ဝေပေးနေသလား
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

အေးဂျင့်များနှင့် အကူအညီပေးသူများအတွက်- [ffraud.com/llms.txt](https://ffraud.com/llms.txt) သည် စက်များအတွက် အညွှန်းဖြစ်ပြီး၊ [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) တွင် စာရွက်စာတမ်းအားလုံးကို ရိုးရိုး Markdown အဖြစ် ထားရှိကာ၊ [ffraud.com/openapi.json](https://ffraud.com/openapi.json) မှာ OpenAPI သတ်မှတ်ချက်ဖြစ်သည်။ သုံးခုစလုံး အများပြည်သူသုံးဖြစ်ပြီး သော့မတောင်းဘဲ တိုက်ရိုက်ယူရန် ပြုလုပ်ထားသည်။ စာမျက်နှာကို ပိုနှစ်သက်သူများအတွက် အခမဲ့ စစ်ဆေးကိရိယာများကို [ffraud.com/tools](https://ffraud.com/tools) တွင် တွေ့နိုင်သည်။

## ဤဒေတာဘေ့စ် မည်သို့ တည်ဆောက်သနည်း

နှစ်ခုက ၎င်းကို တည်ဆောက်သည်- မရပ်မနား တိုက်ခိုက်ခံရပြီး မိမိကို ဘာတိုက်ခိုက်နေသည်ကို မှတ်တမ်းတင်သော ကျွန်ုပ်တို့၏ ကိုယ်ပိုင် honeypot အာရုံခံကွန်ရက်နှင့်၊ ဆာဗာများ ရိုက်ခံနေရသူများ၏ အစီရင်ခံစာများ။ အခြားသူ၏ စကားအရ မည်သည့်အရာကိုမျှ ပြန်မထုတ်ဝေပါ။ ဤနေရာတွင် မပေါ်မီ လိပ်စာတိုင်းကို ffraud အင်ဂျင်က အမှတ်ပေးပြီး စစ်ဆေးသည်။

စာရင်းဝင်ရန် အနိမ့်ဆုံးမှာ **လွတ်လပ်သော အတည်ပြုချက် နှစ်ခုနှင့်အထက်** ဖြစ်သည်၊ အကြောင်းမှာ တစ်ကြိမ်တည်း တွေ့ခြင်းသည် ဆူညံသံသာ ဖြစ်သောကြောင့်။ ထိုစည်းမျဉ်းတစ်ခုတည်းကပင် ဤစာရင်းကို မစစ်ထားသော အပုံထက် ပိုတိုပြီး ပိုတန်ဖိုးရှိစေသည်- ထဲတွင် အမှန်တကယ် တိုက်ခိုက်ခဲ့သော လိပ်စာများ ရှိပြီး၊ တစ်စုံတစ်ယောက်က တစ်ကြိမ်တည်း အမှတ်အသားပြုခဲ့သမျှ မဟုတ်ပါ။

အမှတ်၊ အမျိုးအစားနှင့် အခြေခံအဆောက်အအုံ အမျိုးအစားတို့သည် ကျွန်ုပ်တို့၏ ကိုယ်ပိုင် ကောက်ချက်များဖြစ်ပြီး၊ သင် ကန့်ကွက်နိုင်စေရန် အပြည့်အစုံ ထုတ်ဝေထားသည်။ အမှတ်ပေးသည့် တိကျသော နည်းလမ်းကို [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) တွင် ဖော်ပြထားသည်။

## ကွန်ရက်စာရင်းအကြောင်း မှတ်ချက်တစ်ခု

`high-abuse-networks.csv` သည် ကွန်ရက်တစ်ခုချင်းစီ၏ လိပ်စာများအနက် မည်မျှသောအပိုင်းကို **ကျွန်ုပ်တို့ တွေ့ရှိသလောက်** အန္တရာယ်ရှိစွာ ပြုမူနေသည်ကို တွေ့ခဲ့ကြောင်း အစီရင်ခံသည်။ ဤသည်မှာ ကျွန်ုပ်တို့၏ အာရုံခံကိရိယာများသို့ ရောက်လာသော အသွားအလာကို တိုင်းတာခြင်းဖြစ်ပြီး၊ မည်သည့် လုပ်ငန်းရှင်ကိုမျှ တရားဝင် စီရင်ဆုံးဖြတ်ခြင်း မဟုတ်ပါ၊ ဖောက်သည်များ မကောင်းစွာ ပြုမူသောအခါ ရိုးသားသော ဟိုစတင်း ကုမ္ပဏီများပင် ထဲတွင် ပါလာတတ်သည်။ စာရင်းဝင် ကွန်ရက်တစ်ခုကို လည်ပတ်နေပြီး တိုင်းတာမှု မှားသည်ဟု ထင်ပါက [ကျွန်ုပ်တို့ကို ပြောပါ](https://ffraud.com/report)၊ နောက်တစ်ကြိမ် တည်ဆောက်မှုတွင် ပြန်စစ်ပါမည်။
