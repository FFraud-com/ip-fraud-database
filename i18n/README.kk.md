# IP алаяқтық дерекқоры, әр 30 минут сайын қайта құрылады

<p align="center"><b>1 262 193 расталған зиянды IP мекенжайы және 553 теріс пайдалану деңгейі жоғары желі. Әр мекенжайдың ұпайы, санаты бар және кемінде екі рет тәуелсіз расталған.</b></p>
<p align="center"><sub>MIT лицензиясы &middot; тіркеусіз, API кілтісіз, сұраныс шегісіз &middot; жаңартылды 11.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/kk.svg?v=1789124402" alt="Тірі дерекқорды ffraud.com сайтынан қараңыз" width="540"></a></p>

Бұл [ffraud.com](https://ffraud.com) артында тұрған ашық IP алаяқтық дерекқоры. Ондағы әр мекенжай бір нәрсеге шабуыл жасап тұрғанда байқалған, кемінде екі рет тәуелсіз расталған, 0-ден 100-ге дейін бағаланған және не істеп жүріп ұсталғаны мен қандай инфрақұрылымда жұмыс істейтіні белгіленген. Шабуылдаушылар инфрақұрылымын үздіксіз ауыстырады, сондықтан бұғаттау тізімі соңғы жаңартылуы қандай болса, сонша ғана тұрады: бұл тізім **әр 30 минут сайын** тікелей жұмыс істеп тұрған қозғалтқыштан қайта құрылады. Сіз жүктегеніңіз дәл қазір интернетке шабуыл жасап жатқаны. Тіркеусіз, кілтсіз, шексіз. Оны тікелей желіаралық қалқанға, WAF-қа, тіркелу пішініне немесе алаяқтықты тексеру ағынына құйыңыз.

## Қысқаша

- **1 262 193** расталған зиянды IP мекенжайы, әрқайсысы **кемінде екі рет тәуелсіз** теріс пайдалану кезінде байқалған
- **553** желі, онда біз байқаған мекенжайлар негізінен зиянды және прокси көп болды
- **219 575** бір реттік пошта домені де осы репозиторийде келеді, сондықтан бір рет клондау тіркелу тексерісінің екі жағын да қамтиды
- Әр мекенжай **0-ден 100-ге дейінгі ұпайды**, **қауіп санатын** және көрінген жағдайда **инфрақұрылым түрін** алып жүреді
- **Әр 30 минут сайын** қайта құрылып жарияланады. Commit тарихы өзгерістер журналы, ал [`metadata.json`](metadata.json) құрастырудың нақты уақытын ұстайды
- **MIT лицензиясы**, коммерциялық пайдалануды қоса, автордың аталуы талап етілмейді
- Қарапайым CSV және TXT. Ашатын мұрағат жоқ, үйренетін схема жоқ, орнататын кітапхана жоқ

## Әр жол не айтады

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| Өріс | Нені білдіреді |
|------|------|
| `ip` | Мекенжай. IPv4 да, IPv6 да кездеседі |
| `ffraud_score` | Өзіміздің 0-ден 100-ге дейінгі алаяқтық ұпайымыз. Мұнда жарияланғанның бәрі 50 және одан жоғары |
| `confirmations` | Теріс пайдалануды қанша рет тәуелсіз байқағанымыз. 2-ден төмені тізімге кірмейді; ең нашар мекенжайлар 30-40-қа жетеді |
| `category` | Не істеп жүріп ұсталған: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` немесе `abuse` |
| `type` | Көрінген жағдайда артындағы инфрақұрылым: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. Ажырата алмағанда бос |

## Жылдам бастау

```bash
# Расталған зиянды IP, санаты мен түрімен
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# Ең нашар желілер
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# Бір реттік пошта домендері
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

Әр файл тақырып жолы мен басындағы бірнеше `#` түсініктемесі бар қарапайым мәтін. Оны тікелей `ipset`, `iptables`, WAF ережесіне немесе өзіңіз әйтеуір қолданатын тілдегі `Set` ішіне жіберіңіз.

## Ештеңе жүктемей бір мекенжайды тексеру

Бір нәрсені тексеру үшін бүкіл дерекқорды алудың қажеті жоқ. Ашық API кілт сұрамайды, тәуліктік шегі жоқ және осы репозиторий жаппай жауап беретін сол сұрақтарға бір-бірлеп жауап береді:

```bash
# Бір IP туралы толық ақпарат: ұпай, себеп, санаттар
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Бұл мекенжай бір реттік пе?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Бұл домен тастап кететін пошта жәшіктерін таратады ма?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Агенттер мен көмекшілер үшін: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) машиналарға арналған көрсеткіш, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) бүкіл құжаттаманы таза Markdown түрінде ұстайды, ал [ffraud.com/openapi.json](https://ffraud.com/openapi.json) OpenAPI сипаттамасы. Үшеуі де ашық, кілт сұрамайды және тікелей алуға арналған. Бетті қалайтындар үшін тегін тексергіштер [ffraud.com/tools](https://ffraud.com/tools) сайтында.

## Дерекқор қалай құрылады

Оны екі нәрсе құрайды: үздіксіз шабуылға ұшырайтын және өзіне не шабуыл жасап жатқанын жазып отыратын өз бал тұзағы сенсор желіміз, әрі серверлері соққы алып жатқандардың хабарламалары. Ешнәрсені өзгенің сөзімен қайта жарияламаймыз. Әр мекенжай осында пайда болмас бұрын ffraud қозғалтқышы бағалап, тексереді.

Тізімге енудің табалдырығы **екі және одан көп тәуелсіз растау**, себебі жалғыз көріну тек шу. Дәл осы бір ереже тізімді сүзілмеген үйіндіден қысқа әрі одан құнды етеді: онда шынымен шабуыл жасаған мекенжайлар бар, әлдекім бір рет белгілеген бәрі емес.

Ұпай, санат және инфрақұрылым түрі біздің өз тұжырымдарымыз, оларға қарсы шыға алуыңыз үшін толық жарияланады. Дәл бағалау әдісі [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) сайтында сипатталған.

## Құруға көмектесіңіз

Бұл дерекқор оны пайдаланатындармен бірге өседі. Егер серверлер, fail2ban, WAF немесе өз бал тұзақтарыңызды жүргізсеңіз, сізге шабуыл жасайтынды бізге жіберіңіз, біз оны жариялаймыз: [ffraud.com/report](https://ffraud.com/report) сайтында хабарлаңыз, fail2ban-ды [дайын соңғы нүктеге](https://ffraud.com/docs/contribute) бағыттаңыз немесе осында issue ашыңыз. Әр жіберілімді тексеріп, қайталанғандарын алып тастап, ұпай береміз; расталғаны келесі құрастыруға, яғни жарты сағат ішінде, шығады, қаласаңыз атыңызбен бірге.

## Желілер тізімі туралы ескертпе

`high-abuse-networks.csv` әр желінің мекенжайларының қандай үлесін **біз байқағанымызша** зиянды әрекет үстінде көргенімізді көрсетеді. Бұл сенсорларымызға жеткен трафиктің өлшемі, ешбір оператор туралы құқықтық үкім емес, әрі клиенттері нашар мінез көрсеткенде адал хостинг компаниялары да оған түседі.
