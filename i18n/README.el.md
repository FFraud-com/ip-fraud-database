# Βάση απάτης IP, ανακατασκευάζεται κάθε 30 λεπτά

<p align="center"><b>1.268.512 επιβεβαιωμένα κακόβουλες διευθύνσεις IP και 537 δίκτυα με υψηλή κατάχρηση. Κάθε διεύθυνση βαθμολογημένη, κατηγοριοποιημένη και επιβεβαιωμένη ανεξάρτητα τουλάχιστον δύο φορές.</b></p>
<p align="center"><sub>Άδεια MIT &middot; χωρίς εγγραφή, χωρίς κλειδί API, χωρίς όρια αιτημάτων &middot; ενημερώθηκε 12.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/el.svg?v=1789227009" alt="Δείτε τη ζωντανή βάση στο ffraud.com" width="540"></a></p>

Αυτή είναι η ανοιχτή βάση απάτης IP πίσω από το [ffraud.com](https://ffraud.com). Κάθε διεύθυνση μέσα της παρατηρήθηκε να επιτίθεται σε κάτι, επιβεβαιώθηκε ανεξάρτητα τουλάχιστον δύο φορές, βαθμολογήθηκε από 0 έως 100 και επισημάνθηκε με το τι έκανε όταν πιάστηκε και σε τι είδους υποδομή τρέχει. Οι επιτιθέμενοι αλλάζουν υποδομή διαρκώς, άρα μια λίστα αποκλεισμού αξίζει όσο και η τελευταία της ενημέρωση: αυτή ανακατασκευάζεται **κάθε 30 λεπτά** απευθείας από τη ζωντανή μηχανή. Ό,τι κατεβάζετε είναι αυτό που επιτίθεται στο διαδίκτυο αυτή τη στιγμή. Χωρίς εγγραφή, χωρίς κλειδί, χωρίς όρια. Ρίξτε το κατευθείαν σε τείχος προστασίας, WAF, φόρμα εγγραφής ή γραμμή ελέγχου απάτης.

## Με λίγα λόγια

- **1.268.512** επιβεβαιωμένα κακόβουλες διευθύνσεις IP, καθεμία παρατηρήθηκε σε κατάχρηση **δύο ή περισσότερες ανεξάρτητες φορές**
- **537** δίκτυα όπου οι διευθύνσεις που παρατηρήσαμε ήταν κατά κύριο λόγο κακόβουλες και γεμάτες proxy
- **219.617** αναλώσιμοι τομείς email έρχονται κι αυτοί σε αυτό το αποθετήριο, οπότε ένα μόνο κλωνοποίημα καλύπτει και τα δύο μισά ενός ελέγχου εγγραφής
- Κάθε διεύθυνση φέρει **βαθμολογία από 0 έως 100**, μια **κατηγορία απειλής** και τον **τύπο υποδομής** όταν φαίνεται
- Ανακατασκευάζεται και δημοσιεύεται **κάθε 30 λεπτά**. Το ιστορικό των commit είναι το ημερολόγιο αλλαγών και το [`metadata.json`](metadata.json) φέρει την ακριβή ώρα κατασκευής
- **Άδεια MIT**, εμπορική χρήση περιλαμβάνεται, δεν απαιτείται αναφορά
- Σκέτα CSV και TXT. Τίποτα να αποσυμπιέσετε, κανένα σχήμα να μάθετε, καμία βιβλιοθήκη να εγκαταστήσετε

## Τι περιέχει

| Αρχείο | Γραμμές | Τι είναι |
|------|------:|------|

| [`asn-reputation/high-abuse-networks.csv`](../asn-reputation/high-abuse-networks.csv) | 537 | Δίκτυα των οποίων οι παρατηρούμενες διευθύνσεις ήταν κατά κύριο λόγο κακόβουλες και γεμάτες proxy: η υπογραφή της αλεξίσφαιρης φιλοξενίας |
| [`disposable-email-domains.txt`](../disposable-email-domains.txt) | 219.617 | Αναλώσιμοι και προσωρινοί τομείς email, ένας ανά γραμμή |
| [`ip-intelligence/examples.json`](../ip-intelligence/examples.json) | δείγμα | Πλήρη στοιχεία ανά διεύθυνση: η βαθμολογία, μια αιτία σε απλή γλώσσα και κάθε κατηγορία που αποδώσαμε |
| [`metadata.json`](../metadata.json) | &mdash; | Τρέχουσες μετρήσεις και η ώρα κατασκευής σε UTC, ώστε ένα σενάριο να ξέρει πόσο φρέσκο είναι το αντίγραφό του |

## Τι λέει κάθε γραμμή

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| Πεδίο | Τι δηλώνει |
|------|------|
| `ip` | Η διεύθυνση. Εμφανίζονται και IPv4 και IPv6 |
| `ffraud_score` | Η δική μας βαθμολογία απάτης από 0 έως 100. Ό,τι δημοσιεύεται εδώ είναι 50 και πάνω |
| `confirmations` | Πόσες ανεξάρτητες φορές παρατηρήσαμε την κατάχρηση. Κάτω από 2 δεν καταχωρείται τίποτα· οι χειρότερες διευθύνσεις φτάνουν 30 έως 40 |
| `category` | Σε τι πιάστηκε: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` ή `abuse` |
| `type` | Η υποδομή από πίσω όταν φαίνεται: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. Κενό όταν δεν μπορούμε να το διακρίνουμε |

## Γρήγορη εκκίνηση

```bash
# Επιβεβαιωμένα κακόβουλες IP, με κατηγορία και τύπο
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# Τα χειρότερα δίκτυα
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# Αναλώσιμοι τομείς email
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

Κάθε αρχείο είναι απλό κείμενο με μια γραμμή επικεφαλίδας και λίγα αρχικά σχόλια `#`. Στείλτε το κατευθείαν σε `ipset`, `iptables`, έναν κανόνα WAF ή ένα `Set` στη γλώσσα που ήδη χρησιμοποιείτε.

## Ελέγξτε μία διεύθυνση χωρίς να κατεβάσετε τίποτα

Δεν χρειάζεται να πάρετε όλη τη βάση για να ελέγξετε ένα πράγμα. Το δημόσιο API δεν ζητά κλειδί, δεν έχει ημερήσιο πλαφόν και απαντά ένα προς ένα στα ίδια ερωτήματα που αυτό το αποθετήριο απαντά χύμα:

```bash
# Πλήρη στοιχεία για μία IP: βαθμολογία, αιτία, κατηγορίες
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Είναι αυτή η διεύθυνση αναλώσιμη;
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Μοιράζει αυτός ο τομέας αναλώσιμα γραμματοκιβώτια;
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Για πράκτορες και βοηθούς: το [ffraud.com/llms.txt](https://ffraud.com/llms.txt) είναι το ευρετήριο για μηχανές, το [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) περιέχει όλη την τεκμηρίωση σε καθαρό Markdown και το [ffraud.com/openapi.json](https://ffraud.com/openapi.json) είναι η προδιαγραφή OpenAPI. Και τα τρία είναι δημόσια, δεν ζητούν κλειδί και φτιάχτηκαν για απευθείας λήψη. Όποιος προτιμά σελίδα, θα βρει τους δωρεάν ελέγχους στο [ffraud.com/tools](https://ffraud.com/tools).

## Πώς χτίζεται η βάση

Δύο πράγματα τη χτίζουν: το δικό μας δίκτυο αισθητήρων honeypot, που δέχεται επιθέσεις αδιάκοπα και καταγράφει τι του επιτίθεται, και οι αναφορές από όσους τρώνε τα χτυπήματα στους διακομιστές τους. Τίποτα δεν αναδημοσιεύεται στα λόγια κάποιου άλλου. Κάθε διεύθυνση βαθμολογείται και επαληθεύεται από τη μηχανή του ffraud πριν εμφανιστεί εδώ.

Ο πήχης για την καταχώριση είναι **δύο ή περισσότερες ανεξάρτητες επιβεβαιώσεις**, γιατί μία μεμονωμένη παρατήρηση είναι θόρυβος. Αυτός ακριβώς ο ένας κανόνας κάνει τη λίστα μικρότερη από έναν αφιλτράριστο σωρό και πιο πολύτιμη: περιέχει τις διευθύνσεις που πράγματι επιτίθονταν, όχι ό,τι σημείωσε κάποιος κάποτε μία φορά.

Η βαθμολογία, η κατηγορία και ο τύπος υποδομής είναι δικά μας συμπεράσματα, δημοσιευμένα ολόκληρα ώστε να μπορείτε να διαφωνήσετε. Η ακριβής μέθοδος βαθμολόγησης περιγράφεται στο [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology).

## Βοηθήστε να χτιστεί

Αυτή η βάση μεγαλώνει μαζί με όσους τη χρησιμοποιούν. Αν διαχειρίζεστε διακομιστές, fail2ban, ένα WAF ή δικά σας honeypot, στείλτε μας ό,τι σας επιτίθεται και το δημοσιεύουμε: αναφέρετε στο [ffraud.com/report](https://ffraud.com/report), στρέψτε το fail2ban στο [έτοιμο σημείο](https://ffraud.com/docs/contribute) ή ανοίξτε ένα issue εδώ. Επαληθεύουμε, αφαιρούμε διπλότυπα και βαθμολογούμε κάθε υποβολή· ό,τι επιβεβαιωθεί μπαίνει στην επόμενη κατασκευή, δηλαδή μέσα σε μισή ώρα, με το όνομά σας αν το θέλετε.

## Μια σημείωση για τη λίστα δικτύων

Το `high-abuse-networks.csv` αναφέρει το ποσοστό των διευθύνσεων κάθε δικτύου που **εμείς παρατηρήσαμε** να συμπεριφέρονται κακόβουλα. Είναι μέτρηση της κίνησης που έφτασε στους αισθητήρες μας, όχι νομική κρίση για κανέναν πάροχο, και σοβαρές εταιρείες φιλοξενίας εμφανίζονται εκεί όταν οι πελάτες τους συμπεριφέρονται άσχημα. Αν διαχειρίζεστε καταχωρημένο δίκτυο και θεωρείτε τη μέτρηση λανθασμένη, [πείτε μας](https://ffraud.com/report) και θα την ελέγξουμε ξανά στην επόμενη κατασκευή.
