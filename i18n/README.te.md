# IP మోసం డేటాబేస్, ప్రతి 30 నిమిషాలకు పునర్నిర్మాణం

<p align="center"><b>1,244,317 ధృవీకరించిన హానికర IP చిరునామాలు, 553 అధిక దుర్వినియోగ నెట్‌వర్క్‌లు. ప్రతి చిరునామాకూ స్కోరు, వర్గం ఉన్నాయి, కనీసం రెండుసార్లు స్వతంత్రంగా ధృవీకరించబడింది.</b></p>
<p align="center"><sub>MIT లైసెన్స్ &middot; నమోదు లేదు, API కీ లేదు, అభ్యర్థన పరిమితి లేదు &middot; నవీకరించబడింది 09.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/te.svg?v=1788940811" alt="ffraud.com లో ప్రత్యక్ష డేటాబేస్ చూడండి" width="540"></a></p>

ఇది [ffraud.com](https://ffraud.com) వెనుక నిలిచిన బహిరంగ IP మోసం డేటాబేస్. ఇందులోని ప్రతి చిరునామా దేనిపైనో దాడి చేస్తుండగా గమనించబడింది, కనీసం రెండుసార్లు స్వతంత్రంగా ధృవీకరించబడింది, 0 నుంచి 100 వరకు స్కోరు పొందింది, అది దేనిలో పట్టుబడిందో, ఎలాంటి మౌలిక వసతిపై నడుస్తుందో గుర్తుగా వేయబడింది. దాడి చేసేవారు మౌలిక వసతిని ఆపకుండా మారుస్తారు, కాబట్టి ఏ నిరోధక జాబితా అయినా దాని చివరి నవీకరణ విలువే: ఇది **ప్రతి 30 నిమిషాలకు** నేరుగా నడుస్తున్న ఇంజిన్ నుంచి తిరిగి నిర్మించబడుతుంది. మీరు దించుకునేదే ఈ క్షణం ఇంటర్నెట్‌పై దాడి చేస్తున్నది. నమోదు లేదు, కీ లేదు, పరిమితి లేదు. దీన్ని నేరుగా ఫైర్‌వాల్, WAF, నమోదు ఫారం లేదా మోసం తనిఖీ ప్రవాహంలో పోయండి.

## క్లుప్తంగా

- **1,244,317** ధృవీకరించిన హానికర IP చిరునామాలు, ప్రతిదీ **కనీసం రెండుసార్లు స్వతంత్రంగా** దుర్వినియోగం చేస్తుండగా గమనించబడింది
- **553** నెట్‌వర్క్‌లు, అక్కడ మేము గమనించిన చిరునామాలు ఎక్కువగా హానికరమైనవి, ప్రాక్సీలతో నిండినవి
- **219,507** ఒకసారి వాడే ఇమెయిల్ డొమైన్‌లు కూడా ఇదే రిపోజిటరీలో వస్తాయి, కాబట్టి ఒక్కసారి క్లోన్ చేస్తే నమోదు తనిఖీ రెండు వైపులా కప్పబడుతుంది
- ప్రతి చిరునామా **0 నుంచి 100 వరకు స్కోరు**, ఒక **ముప్పు వర్గం**, కనిపిస్తే **మౌలిక వసతి రకం** మోసుకొస్తుంది
- **ప్రతి 30 నిమిషాలకు** తిరిగి నిర్మించి ప్రచురించబడుతుంది. commit చరిత్రే మార్పుల నమోదు, [`metadata.json`](metadata.json) లో నిర్మాణ ఖచ్చిత సమయం ఉంటుంది
- **MIT లైసెన్స్**, వాణిజ్య వినియోగంతో సహా, మూలం పేర్కొనడం అవసరం లేదు
- సాదా CSV, TXT. విప్పాల్సిన ఆర్కైవ్ లేదు, నేర్చుకోవాల్సిన స్కీమా లేదు, ఇన్‌స్టాల్ చేయాల్సిన లైబ్రరీ లేదు

## ప్రతి వరుస ఏమి చెబుతుంది

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| ఫీల్డ్ | ఏమి చెబుతుంది |
|------|------|
| `ip` | చిరునామా. IPv4, IPv6 రెండూ కనిపిస్తాయి |
| `ffraud_score` | మా సొంత 0 నుంచి 100 మోసం స్కోరు. ఇక్కడ ప్రచురించేదంతా 50 లేదా పైన |
| `confirmations` | ఆ దుర్వినియోగాన్ని ఎన్నిసార్లు స్వతంత్రంగా గమనించామో. 2 కంటే తక్కువకు ఏదీ జాబితా కాదు; అత్యంత చెడ్డ చిరునామాలు 30 నుంచి 40 దాకా చేరతాయి |
| `category` | దేనిలో పట్టుబడింది: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` లేదా `abuse` |
| `type` | కనిపిస్తే దాని వెనుక మౌలిక వసతి: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. వేరు చేయలేనప్పుడు ఖాళీ |

## త్వరిత ప్రారంభం

```bash
# ధృవీకరించిన హానికర IP, వర్గం మరియు రకంతో
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# అత్యంత చెడ్డ నెట్‌వర్క్‌లు
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# ఒకసారి వాడే ఇమెయిల్ డొమైన్‌లు
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

ప్రతి ఫైల్ ఒక శీర్షిక వరుస, మొదట్లో కొన్ని `#` వ్యాఖ్యలతో ఉన్న సాదా టెక్స్ట్. దాన్ని నేరుగా `ipset`, `iptables`, ఒక WAF నియమం, లేదా మీరు ఇప్పటికే వాడుతున్న భాషలోని `Set` కు పంపండి.

## ఏమీ డౌన్‌లోడ్ చేయకుండా ఒక చిరునామాను తనిఖీ చేయండి

ఒక్క విషయం తనిఖీ చేయడానికి మొత్తం డేటాబేస్ తీసుకోవాల్సిన అవసరం లేదు. బహిరంగ API కీ అడగదు, రోజువారీ పరిమితి లేదు, ఈ రిపోజిటరీ గుంపుగా జవాబిచ్చే అవే ప్రశ్నలకు ఒక్కొక్కటిగా జవాబిస్తుంది:

```bash
# ఒక IP గురించి పూర్తి సమాచారం: స్కోరు, కారణం, వర్గాలు
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# ఈ చిరునామా ఒకసారి వాడేదా?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# ఈ డొమైన్ పారేసే మెయిల్‌బాక్స్‌లను పంచుతోందా?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

ఏజెంట్లు, సహాయకుల కోసం: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) యంత్రాల కోసం సూచిక, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) మొత్తం డాక్యుమెంటేషన్‌ను సాదా Markdown రూపంలో ఉంచుతుంది, [ffraud.com/openapi.json](https://ffraud.com/openapi.json) OpenAPI వివరణ. మూడూ బహిరంగమే, కీ అడగవు, నేరుగా తీసుకోవడానికే తయారు చేయబడ్డాయి. పేజీ ఇష్టపడేవారికి ఉచిత తనిఖీ సాధనాలు [ffraud.com/tools](https://ffraud.com/tools) లో ఉన్నాయి.

## ఈ డేటాబేస్ ఎలా నిర్మించబడుతుంది

రెండు విషయాలు దీన్ని నిర్మిస్తాయి: నిరంతరం దాడికి గురై, తనపై ఏమి దాడి చేస్తుందో నమోదు చేసే మా సొంత హనీపాట్ సెన్సార్ నెట్‌వర్క్, మరియు సర్వర్లు దెబ్బలు తింటున్న వారి నివేదికలు. వేరొకరి మాటపై మేము దేన్నీ మళ్లీ ప్రచురించము. ఇక్కడ కనిపించే ముందు ప్రతి చిరునామాకు ffraud ఇంజిన్ స్కోరు ఇచ్చి ధృవీకరిస్తుంది.

జాబితాలో చేరడానికి గీత **కనీసం రెండు స్వతంత్ర ధృవీకరణలు**, ఎందుకంటే ఒకే ఒక్క దర్శనం కేవలం శబ్దం. ఈ ఒక్క నియమమే ఈ జాబితాను వడపోయని కుప్ప కంటే చిన్నదిగా, దాని కంటే విలువైనదిగా చేస్తుంది: ఇందులో నిజంగా దాడి చేసిన చిరునామాలు ఉన్నాయి, ఎవరో ఒకసారి గుర్తు పెట్టినదంతా కాదు.

స్కోరు, వర్గం, మౌలిక వసతి రకం మా సొంత నిర్ధారణలు, మీరు వాటిని ఖండించగలిగేలా పూర్తిగా ప్రచురిస్తాం. ఖచ్చితమైన స్కోరింగ్ పద్ధతి [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) లో వివరించబడింది.

## నెట్‌వర్క్ జాబితా గురించి ఒక గమనిక
