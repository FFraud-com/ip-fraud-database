# IP फसवणूक डेटाबेस, दर 30 मिनिटांनी पुन्हा बांधला जातो

<p align="center"><b>1,257,053 पडताळलेले घातक IP पत्ते आणि 553 अधिक गैरवापर असलेली जाळी. प्रत्येक पत्त्याला गुण, वर्ग आहेत आणि किमान दोनदा स्वतंत्रपणे पडताळला गेला आहे.</b></p>
<p align="center"><sub>MIT परवाना &middot; नोंदणी नाही, API किल्ली नाही, विनंत्यांची मर्यादा नाही &middot; अद्ययावत 11.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/mr.svg?v=1789090207" alt="ffraud.com वर थेट डेटाबेस पाहा" width="540"></a></p>

हा [ffraud.com](https://ffraud.com) मागे उभा असलेला खुला IP फसवणूक डेटाबेस आहे. यातील प्रत्येक पत्ता कशावर तरी हल्ला करताना दिसला, किमान दोनदा स्वतंत्रपणे पडताळला गेला, 0 ते 100 दरम्यान गुण मिळाले, आणि तो कशात पकडला गेला व कोणत्या प्रकारच्या पायाभूत सुविधेवर चालतो हे नोंदवले गेले. हल्लेखोर सतत आपली पायाभूत सुविधा बदलतात, त्यामुळे कोणत्याही अडवणूक यादीची किंमत तिच्या शेवटच्या अद्ययावतीइतकीच असते: ही यादी **दर 30 मिनिटांनी** थेट चालू इंजिनमधून पुन्हा बांधली जाते. तुम्ही जे उतरवता तेच याच क्षणी इंटरनेटवर हल्ला करत आहे. नोंदणी नाही, किल्ली नाही, मर्यादा नाही. थेट फायरवॉल, WAF, नोंदणी अर्ज किंवा फसवणूक तपासणीच्या साखळीत टाका.

## थोडक्यात

- **1,257,053** पडताळलेले घातक IP पत्ते, प्रत्येक **किमान दोनदा स्वतंत्रपणे** गैरवापर करताना दिसला
- **553** जाळी जिथे आम्ही पाहिलेले पत्ते बहुतांशी घातक आणि प्रॉक्सीने भरलेले होते
- **219,575** एकदाच वापरायचे ईमेल डोमेनही याच भांडारात येतात, म्हणजे एकदा क्लोन केले की नोंदणी तपासणीचे दोन्ही भाग झाकले जातात
- प्रत्येक पत्ता **0 ते 100 गुण**, एक **धोक्याचा वर्ग**, आणि दिसत असल्यास **पायाभूत सुविधेचा प्रकार** घेऊन येतो
- **दर 30 मिनिटांनी** पुन्हा बांधून प्रसिद्ध होते. commit चा इतिहासच बदलांची नोंद आहे, आणि [`metadata.json`](metadata.json) मध्ये बांधणीची नेमकी वेळ असते
- **MIT परवाना**, व्यावसायिक वापरासह, श्रेय देणे आवश्यक नाही
- साधे CSV आणि TXT. उघडायला संग्रह नाही, शिकायला रचना नाही, बसवायला ग्रंथालय नाही

## प्रत्येक ओळ काय सांगते

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| क्षेत्र | काय सांगते |
|------|------|
| `ip` | पत्ता. IPv4 आणि IPv6 दोन्ही येतात |
| `ffraud_score` | आमचा स्वतःचा 0 ते 100 फसवणूक गुण. इथे प्रसिद्ध होणारे सर्व 50 किंवा त्याहून वर आहे |
| `confirmations` | तो गैरवापर आम्ही किती वेळा स्वतंत्रपणे पाहिला. 2 पेक्षा कमी असल्यास काहीही यादीत येत नाही; सर्वात वाईट पत्ते 30 ते 40 पर्यंत पोहोचतात |
| `category` | कशात पकडला गेला: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` किंवा `abuse` |
| `type` | दिसत असल्यास त्यामागची पायाभूत सुविधा: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. ओळखता न आल्यास रिकामे |

## झटपट सुरुवात

```bash
# पडताळलेले घातक IP, वर्ग आणि प्रकारासह
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# सर्वात वाईट जाळी
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# एकदाच वापरायचे ईमेल डोमेन
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

प्रत्येक फाइल एक शीर्षक ओळ आणि सुरुवातीला काही `#` टिपांसह साधा मजकूर आहे. ती थेट `ipset`, `iptables`, एखाद्या WAF नियमाकडे, किंवा तुम्ही आधीच वापरत असलेल्या भाषेतील `Set` कडे पाठवा.

## काहीही न उतरवता एक पत्ता तपासा

एक गोष्ट तपासण्यासाठी संपूर्ण डेटाबेस घ्यायची गरज नाही. सार्वजनिक API किल्ली मागत नाही, त्याला रोजची मर्यादा नाही, आणि हे भांडार जे प्रश्न गठ्ठ्याने सोडवते तेच प्रश्न ते एकेक करून सोडवते:

```bash
# एका IP ची संपूर्ण माहिती: गुण, कारण, वर्ग
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# हा पत्ता एकदाच वापरायचा आहे का?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# हे डोमेन फेकून द्यायच्या टपालपेट्या वाटते का?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

एजंट आणि सहाय्यकांसाठी: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) ही यंत्रांसाठीची अनुक्रमणिका आहे, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) मध्ये संपूर्ण दस्तऐवज साध्या Markdown रूपात आहे, आणि [ffraud.com/openapi.json](https://ffraud.com/openapi.json) हे OpenAPI तपशील आहे. तिन्ही सार्वजनिक आहेत, किल्ली मागत नाहीत, आणि थेट घेण्यासाठीच बनवली आहेत. ज्यांना पान आवडते त्यांच्यासाठी मोफत तपासणी साधने [ffraud.com/tools](https://ffraud.com/tools) वर आहेत.

## हा डेटाबेस कसा उभा राहतो

दोन गोष्टी तो उभारतात: सतत हल्ला होणारे आणि आपल्यावर काय हल्ला करते ते नोंदवणारे आमचे स्वतःचे मधाच्या सापळ्यांचे संवेदक जाळे, आणि ज्यांचे सर्व्हर मार खात आहेत त्यांचे अहवाल. दुसऱ्याच्या सांगण्यावरून आम्ही काहीही पुन्हा प्रसिद्ध करत नाही. इथे दिसण्याआधी प्रत्येक पत्त्याला ffraud इंजिन गुण देते आणि तपासते.

यादीत येण्याची पातळी **किमान दोन स्वतंत्र पडताळण्या** आहे, कारण एकच दर्शन म्हणजे नुसता गोंगाट. हाच एक नियम या यादीला न गाळलेल्या ढिगाऱ्यापेक्षा लहान आणि त्याहून मौल्यवान करतो: यात खरोखर हल्ला करणारे पत्ते आहेत, कुणीतरी कधीतरी एकदा खूण केलेले सर्वकाही नाही.

गुण, वर्ग आणि पायाभूत सुविधेचा प्रकार हे आमचे स्वतःचे निष्कर्ष आहेत, तुम्हाला त्यांना विरोध करता यावा म्हणून पूर्णपणे प्रसिद्ध केले जातात. गुण देण्याची नेमकी पद्धत [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) वर लिहिली आहे.

## उभारणीत मदत करा

हा डेटाबेस तो वापरणाऱ्यांसोबतच वाढतो. तुम्ही सर्व्हर, fail2ban, WAF किंवा स्वतःचे मधाचे सापळे चालवत असाल, तर तुमच्यावर हल्ला करणारे आम्हाला पाठवा, आम्ही ते प्रसिद्ध करू: [ffraud.com/report](https://ffraud.com/report) वर कळवा, fail2ban ला [तयार टोकाकडे](https://ffraud.com/docs/contribute) वळवा, किंवा इथेच एक issue उघडा. प्रत्येक नोंद आम्ही तपासतो, दुबार काढतो आणि गुण देतो; पडताळलेली पुढच्या बांधणीत, म्हणजे अर्ध्या तासात, प्रसिद्ध होते, हवे असल्यास तुमच्या नावासह.

## जाळ्यांच्या यादीबद्दल एक टीप

`high-abuse-networks.csv` प्रत्येक जाळ्यातील किती भाग पत्ते **आम्ही पाहिल्याप्रमाणे** घातक वागताना दिसले ते सांगते. हे आमच्या संवेदकांपर्यंत पोहोचलेल्या वाहतुकीचे मोजमाप आहे, कोणत्याही चालकावरचा कायदेशीर निर्णय नाही, आणि ग्राहक वाईट वागले की प्रामाणिक होस्टिंग कंपन्याही त्यात येतात. तुम्ही यादीतले जाळे चालवत असाल आणि मोजमाप चुकीचे वाटत असेल, तर [आम्हाला सांगा](https://ffraud.com/report), पुढच्या बांधणीत पुन्हा तपासू.
