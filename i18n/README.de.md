# IP-Betrugsdatenbank, alle 30 Minuten neu gebaut

<p align="center"><b>1.229.125 bestätigt bösartige IP-Adressen und 553 stark auffällige Netze. Jede Adresse bewertet, kategorisiert und mindestens zweimal unabhängig bestätigt.</b></p>
<p align="center"><sub>MIT-Lizenz &middot; keine Anmeldung, kein API-Schlüssel, kein Limit &middot; aktualisiert am 07.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/de.svg?v=1788787801" alt="Die Live-Datenbank auf ffraud.com ansehen" width="540"></a></p>

Das ist die offene IP-Betrugsdatenbank hinter [ffraud.com](https://ffraud.com). Jede Adresse darin wurde beim Angriff beobachtet, mindestens zweimal unabhängig bestätigt, von 0 bis 100 bewertet und damit beschriftet, wobei sie erwischt wurde und auf welcher Infrastruktur sie läuft. Angreifer wechseln ihre Infrastruktur ständig, deshalb ist eine Sperrliste nur so viel wert wie ihre letzte Aktualisierung: diese hier wird **alle 30 Minuten** direkt aus der laufenden Engine neu gebaut. Was Sie herunterladen, greift das Internet gerade jetzt an. Keine Anmeldung, kein API-Schlüssel, kein Limit. Rein damit in eine Firewall, eine WAF, ein Anmeldeformular oder eine Betrugsprüfung.

## Die wichtigsten Zahlen

- **1.229.125** bestätigt bösartige IP-Adressen, jede **mindestens zweimal unabhängig** beim Missbrauch beobachtet
- **553** Netze, in denen die von uns beobachteten Adressen überwiegend bösartig und proxylastig waren
- **219.465** Wegwerf-E-Mail-Domains liegen ebenfalls in diesem Repository, ein Klon deckt also beide Hälften einer Anmeldeprüfung ab
- Jede Adresse trägt einen **Score von 0 bis 100**, eine **Bedrohungskategorie** und den **Infrastrukturtyp**, soweit erkennbar
- Wird **alle 30 Minuten** neu gebaut und hochgeladen. Die Commit-Historie ist das Änderungsprotokoll, und [`metadata.json`](metadata.json) trägt die genaue Bauzeit
- **MIT-Lizenz**, kommerzielle Nutzung eingeschlossen, keine Namensnennung nötig
- Schlichtes CSV und TXT. Kein Archiv zum Entpacken, kein Schema zum Lernen, keine Bibliothek zum Installieren

## Was jede Zeile aussagt

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| Feld | Was es aussagt |
|------|------|
| `ip` | Die Adresse. IPv4 und IPv6 kommen beide vor |
| `ffraud_score` | Unser eigener Betrugs-Score von 0 bis 100. Alles hier Veröffentlichte liegt bei 50 oder darüber |
| `confirmations` | Wie oft wir den Missbrauch unabhängig beobachtet haben. Unter 2 wird nichts gelistet; die schlimmsten Adressen tragen 30 bis 40 |
| `category` | Wobei sie erwischt wurde: `c2`, `malware`, `botnet`, `brute_force`, `web_attack`, `scanner`, `phishing`, `spam` oder `abuse` |
| `type` | Die dahinterliegende Infrastruktur, soweit sichtbar: `proxy`, `vpn`, `tor`, `datacenter`, `mobile`. Leer, wenn wir es nicht erkennen können |

## Schnellstart

```bash
# Bestätigt bösartige IPs, mit Kategorie und Typ
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# Die schlimmsten Netze
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# Wegwerf-E-Mail-Domains
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

Jede Datei ist reiner Text mit einer Kopfzeile und ein paar führenden `#`-Kommentaren. Direkt weiterleiten an `ipset`, `iptables`, eine WAF-Regel oder ein `Set` in der Sprache, die Sie ohnehin benutzen.

## Eine einzelne Adresse prüfen, ohne etwas herunterzuladen

Sie müssen nicht die ganze Datenbank ziehen, um eine einzelne Sache zu prüfen. Die öffentliche API braucht keinen Schlüssel, hat kein Tageslimit und beantwortet einzeln dieselben Fragen wie dieses Repository in der Masse:

```bash
# Vollständige Auskunft zu einer IP: Score, Begründung, Kategorien
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# Ist diese Adresse eine Wegwerfadresse?
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# Vergibt diese Domain Wegwerf-Postfächer?
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

Für Agenten und Assistenten: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) ist der Maschinen-Index, [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) enthält jede Doku-Seite als reines Markdown, und [ffraud.com/openapi.json](https://ffraud.com/openapi.json) ist die OpenAPI-Spezifikation. Alle drei sind öffentlich, brauchen keinen Schlüssel und sind zum direkten Abruf gedacht. Wer lieber eine Seite benutzt, findet die kostenlosen Prüfwerkzeuge unter [ffraud.com/tools](https://ffraud.com/tools).

## Wie die Datenbank entsteht

Zwei Dinge bauen sie: unser eigenes Honeypot-Sensornetz, das ununterbrochen angegriffen wird und aufzeichnet, was es angreift, und Meldungen von den Leuten, deren Server getroffen werden. Nichts wird auf fremdes Wort hin weiterveröffentlicht. Jede Adresse wird von der ffraud-Engine bewertet und geprüft, bevor sie hier auftaucht.

Die Hürde für die Aufnahme sind **mindestens zwei unabhängige Bestätigungen**, denn eine einzelne Sichtung ist Rauschen. Genau diese Regel macht die Liste kleiner als eine ungefilterte Sammlung und wertvoller: Sie enthält die Adressen, die wirklich angegriffen haben, nicht alles, was jemand einmal markiert hat.

Der Score, die Kategorie und der Infrastrukturtyp sind unsere eigenen Schlussfolgerungen, vollständig veröffentlicht, damit Sie ihnen widersprechen können. Das genaue Bewertungsverfahren steht unter [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology).

## Mitbauen

Diese Datenbank wächst mit den Leuten, die sie benutzen. Wer Server, fail2ban, eine WAF oder eigene Honeypots betreibt, schickt uns, was ihn angreift, und wir veröffentlichen es: melden unter [ffraud.com/report](https://ffraud.com/report), fail2ban auf den [fertigen Endpunkt](https://ffraud.com/docs/contribute) zeigen lassen oder hier ein Issue öffnen. Wir prüfen, entdoppeln und bewerten jede Einsendung; bestätigte gehen im nächsten Build mit, also innerhalb einer halben Stunde, auf Wunsch mit Namensnennung.

## Ein Hinweis zur Netzliste

`high-abuse-networks.csv` gibt an, welcher Anteil der Adressen eines Netzes sich **nach unserer Beobachtung** bösartig verhalten hat. Das ist eine Messung des Verkehrs, der unsere Sensoren erreicht hat, kein rechtliches Urteil über einen Betreiber, und seriöse Hoster tauchen dort auf, wenn ihre Kunden sich danebenbenehmen. Wer ein gelistetes Netz betreibt und die Messung für falsch hält, [sagt uns Bescheid](https://ffraud.com/report), dann prüfen wir im nächsten Build erneut.
