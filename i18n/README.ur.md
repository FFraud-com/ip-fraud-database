# آئی پی فراڈ ڈیٹابیس، ہر 30 منٹ بعد دوبارہ تعمیر

<p align="center"><b>1,265,197 تصدیق شدہ نقصان دہ آئی پی پتے اور 553 زیادہ بدسلوکی والے نیٹ ورک۔ ہر پتے کا اسکور اور زمرہ ہے اور کم از کم دو بار آزادانہ تصدیق ہو چکی ہے۔</b></p>
<p align="center"><sub>MIT لائسنس &middot; رجسٹریشن نہیں، API کلید نہیں، درخواستوں کی حد نہیں &middot; تازہ کاری 11.09.2026</sub></p>
<p align="center"><a href="https://ffraud.com/docs/open-data"><img src="https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/assets/cta/ur.svg?v=1789162209" alt="ffraud.com پر زندہ ڈیٹابیس دیکھیں" width="540"></a></p>

یہ [ffraud.com](https://ffraud.com) کے پیچھے کھڑا کھلا آئی پی فراڈ ڈیٹابیس ہے۔ اس میں موجود ہر پتہ کسی چیز پر حملہ کرتے ہوئے دیکھا گیا، کم از کم دو بار آزادانہ تصدیق ہوئی، 0 سے 100 کے درمیان اسکور ملا، اور اس پر یہ لیبل لگا کہ وہ کس کام میں پکڑا گیا اور کس قسم کے بنیادی ڈھانچے پر چلتا ہے۔ حملہ آور مسلسل اپنا ڈھانچہ بدلتے رہتے ہیں، اس لیے کسی بلاک لسٹ کی قیمت اس کی آخری تازہ کاری کے برابر ہوتی ہے: یہ فہرست **ہر 30 منٹ بعد** براہِ راست چلتے ہوئے انجن سے نئے سرے سے بنتی ہے۔ آپ جو ڈاؤن لوڈ کرتے ہیں، وہی اس وقت انٹرنیٹ پر حملہ کر رہا ہے۔ نہ رجسٹریشن، نہ کلید، نہ کوئی حد۔ اسے سیدھا فائروال، WAF، سائن اپ فارم یا فراڈ جانچ کی لائن میں ڈال دیجیے۔

## مختصراً

- **1,265,197** تصدیق شدہ نقصان دہ آئی پی پتے، ہر ایک **کم از کم دو بار آزادانہ طور پر** بدسلوکی کرتے دیکھا گیا
- **553** نیٹ ورک جہاں ہمارے دیکھے ہوئے پتے زیادہ تر نقصان دہ اور پراکسی سے بھرے تھے
- **219,608** یک بار استعمال ای میل ڈومین بھی اسی ریپوزٹری میں آتے ہیں، تو ایک بار کلون کرنے سے سائن اپ جانچ کے دونوں حصے ڈھک جاتے ہیں
- ہر پتے کے ساتھ **0 سے 100 کا اسکور**، ایک **خطرے کا زمرہ**، اور جہاں نظر آئے وہاں **بنیادی ڈھانچے کی قسم** ہوتی ہے
- **ہر 30 منٹ بعد** نئے سرے سے بن کر شائع ہوتا ہے۔ کمٹ کی تاریخ ہی تبدیلیوں کا ریکارڈ ہے، اور [`metadata.json`](metadata.json) میں تعمیر کا درست وقت ہوتا ہے
- **MIT لائسنس**، تجارتی استعمال سمیت، حوالہ دینا لازمی نہیں
- سادہ CSV اور TXT۔ نہ کھولنے کو کوئی آرکائیو، نہ سیکھنے کو کوئی اسکیما، نہ نصب کرنے کو کوئی لائبریری

## ہر سطر کیا بتاتی ہے

```csv
ip,ffraud_score,confirmations,category,type
80.82.77.33,95,40,c2,proxy
2.57.121.25,95,36,c2,proxy
193.46.255.86,95,33,c2,proxy
```

| خانہ | کیا بتاتا ہے |
|------|------|
| `ip` | پتہ۔ IPv4 اور IPv6 دونوں آتے ہیں |
| `ffraud_score` | ہمارا اپنا 0 سے 100 فراڈ اسکور۔ یہاں شائع ہونے والا سب کچھ 50 یا اس سے اوپر ہے |
| `confirmations` | ہم نے کتنی بار آزادانہ طور پر بدسلوکی دیکھی۔ 2 سے کم پر کچھ درج نہیں ہوتا؛ بدترین پتے 30 سے 40 تک پہنچتے ہیں |
| `category` | کس کام میں پکڑا گیا: `c2`، `malware`، `botnet`، `brute_force`، `web_attack`، `scanner`، `phishing`، `spam` یا `abuse` |
| `type` | جہاں نظر آئے وہاں پیچھے کا ڈھانچہ: `proxy`، `vpn`، `tor`، `datacenter`، `mobile`۔ جہاں ہم پہچان نہ سکیں وہاں خالی |

## فوری آغاز

```bash
# تصدیق شدہ نقصان دہ آئی پی، زمرے اور قسم کے ساتھ
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/threat-ips/confirmed-abusive.csv

# بدترین نیٹ ورک
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/asn-reputation/high-abuse-networks.csv

# یک بار استعمال ای میل ڈومین
curl -s https://raw.githubusercontent.com/FFraud-com/ip-fraud-database/main/disposable-email-domains.txt
```

ہر فائل سادہ متن ہے، ایک سرخی کی سطر اور شروع میں چند `#` تبصروں کے ساتھ۔ اسے سیدھا `ipset`، `iptables`، کسی WAF قاعدے، یا جس زبان میں آپ پہلے سے کام کرتے ہیں اس کے `Set` میں بھیج دیجیے۔

## کچھ ڈاؤن لوڈ کیے بغیر ایک پتہ جانچیں

ایک چیز جانچنے کے لیے پورا ڈیٹابیس لینے کی ضرورت نہیں۔ عوامی API کوئی کلید نہیں مانگتا، اس کی روزانہ کوئی حد نہیں، اور یہ ریپوزٹری جن سوالوں کا جواب اکٹھا دیتی ہے، وہی جواب یہ ایک ایک کر کے دیتا ہے:

```bash
# ایک آئی پی کی مکمل معلومات: اسکور، وجہ، زمرے
curl -s https://api.ffraud.com/public/ip/80.82.77.33

# کیا یہ پتہ یک بار استعمال کا ہے؟
curl -s -X POST https://api.ffraud.com/public/email/check -H 'content-type: application/json' -d '{"email":"test@mailinator.com"}'

# کیا یہ ڈومین پھینک دینے والے میل باکس بانٹتا ہے؟
curl -s https://api.ffraud.com/public/domain/mailinator.com
```

ایجنٹوں اور معاونین کے لیے: [ffraud.com/llms.txt](https://ffraud.com/llms.txt) مشینوں کے لیے اشاریہ ہے، [ffraud.com/llms-full.txt](https://ffraud.com/llms-full.txt) میں پوری دستاویزات سادہ Markdown میں ہیں، اور [ffraud.com/openapi.json](https://ffraud.com/openapi.json) OpenAPI تفصیل ہے۔ تینوں عوامی ہیں، کوئی کلید نہیں مانگتے، اور براہِ راست حاصل کرنے کے لیے ہی بنے ہیں۔ جو صفحہ پسند کریں، ان کے لیے مفت جانچ کے اوزار [ffraud.com/tools](https://ffraud.com/tools) پر ہیں۔

## یہ ڈیٹابیس کیسے بنتا ہے

دو چیزیں اسے بناتی ہیں: ہمارا اپنا شہد کے برتن والا سینسر نیٹ ورک، جس پر مسلسل حملے ہوتے ہیں اور جو لکھتا رہتا ہے کہ اس پر کون حملہ کر رہا ہے، اور ان لوگوں کی اطلاعات جن کے سرور مار کھا رہے ہیں۔ کسی اور کے کہنے پر ہم کچھ بھی دوبارہ شائع نہیں کرتے۔ یہاں آنے سے پہلے ہر پتے کو ffraud انجن اسکور دیتا اور جانچتا ہے۔

فہرست میں آنے کی شرط **کم از کم دو آزاد تصدیقیں** ہیں، کیونکہ ایک بار کا نظارہ محض شور ہے۔ یہی ایک قاعدہ اس فہرست کو بغیر چھانے ڈھیر سے چھوٹا اور اس سے زیادہ قیمتی بناتا ہے: اس میں وہی پتے ہیں جو واقعی حملہ کر رہے تھے، ہر وہ چیز نہیں جسے کسی نے کبھی ایک بار نشان زد کر دیا ہو۔

اسکور، زمرہ اور بنیادی ڈھانچے کی قسم ہمارے اپنے نتائج ہیں، پورے کے پورے شائع کیے جاتے ہیں تاکہ آپ ان سے اختلاف کر سکیں۔ اسکور دینے کا درست طریقہ [ffraud.com/docs/methodology](https://ffraud.com/docs/methodology) پر لکھا ہے۔
